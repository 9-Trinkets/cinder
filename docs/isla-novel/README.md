# 艾拉輕小說・企劃大綱（柳屋記事）

> 第一人稱主視角（艾拉・馬洛純一人稱主線）・正史改編・療癒系文學輕小說格式・繁體中文（台灣）・正文一律純中文

---

## 作品簡介（Synopsis）

> 在孩子開口說話之前，他們的雙手就已經說出了實話。

費城林登街轉角的老垂柳下，有一棟三層樓的紅磚老宅——「柳屋」。
那扇深鼠尾草綠的大門上有兩個門把：一個在大人的高度，另一個在六歲孩子伸手就能勾到的地方。屋裡沒有時鐘，時間是由暖氣管的輕敲聲、街角教堂的鐘聲，以及一顆綠色洋梨發條計時器來丈量的。

三十九歲的兒童臨床心理師艾拉・馬洛每天騎著弟弟為她組裝的舊單車來這裡上班。她的「圖書館之友」帆布托特包裡，總是收著一塊洗軟的燕麥色亞麻方布、一本套著深綠帆布書衣的日製方格手帳，以及幾本她自己至少讀過兩遍的繪本。

在開口說話之前，孩子們的雙手早就說出了實話——脫下來的鞋尖怎麼對齊牆壁、哪些玩具被分進哪個箱子、哪一頁故事讓人忍不住移開視線。在柳屋，艾拉從不急著追問「為什麼」，也不負責把誰「修好」。她只是把椅子坐低，陪那些被大人誇讚「懂事、從不惹麻煩」的孩子安靜待上一小時，直到他們終於敢把懷裡抱得太緊的重量，輕輕放到地上。

## 1. 核心世界觀與敘事定位

- **主角艾拉・馬洛（Dr. Isla Marlow，39 歲）**：
  費城非營利兒童心理諮商中心「柳屋（Willow House）」的臨床兒童心理師。孩子們都直接叫她「艾拉」。
  - **性格與習慣**：耐心、冷靜、觀察入微，帶點克制的乾冷幽默，總是習慣比別人晚半秒才開口回答。她相信孩子在用嘴巴說話之前，雙手就已經說出了實話——哪個玩具放在哪裡、把什麼排成一列、走路時刻意繞開哪一塊地磚。
  - **傾聽的起源（弟弟丹尼 Danny）**：在賓州雷丁（Reading）鎮外的安靜家庭長大，母親是醫院護理師，父親是水電工。小她兩歲的弟弟丹尼四歲前不曾開口說話，後來確診自閉症。童年時唯一能走進丹尼世界裡的，是一本他讓艾拉反覆念了**兩百遍**的繪本。只要視線裡看得到玩具，丹尼就無法專心看書，於是十歲的艾拉拿了一條舊毛巾蓋住他的玩具架，並肩坐在他身旁（而不是面對面盯著他），一頁一頁重讀。這成了她日後所有工作方法的源頭——但她從不向任何人提起，因為丹尼的人生屬於丹尼自己。
  - **職涯與日常**：24 至 28 歲在公立圖書館分館擔任兒童圖書管理員；28 至 33 歲半工半讀攻讀兒童臨床心理學博士；34 歲起進入柳屋工作至今五年。薪水微薄、仍在償還學貸，住在離柳屋兩站公車距離的一房公寓，不論晴雨都騎著丹尼親手為她組裝的腳踏車通勤。唯一的奢侈是自掏妖包購買繪本，家裡養著一隻名叫「註腳（Footnote，艾拉平時也喚牠註腳先生）」的 17 歲老虎斑貓。
- **舞台：柳屋（Willow House）**：
  位於費城林登街（Linden Street，單行小巷）與卡洛威大道（Calloway Avenue，雙向公車幹道）轉角的 1920 年代三層紅磚雙拼老宅。
  - **環境特徵**：前院有一棵大得過頭的老垂柳，樹根把一塊人行道水泥磚頂得像掀開的蓋子；深邃的前廊掛著一張誰也不准拆掉的木吊椅，大門漆成深鼠尾草綠。屋內沒有時鐘，時間由卡洛威大道公車靠站的氣壓嘆息聲、暖氣管的敲擊聲與街角教堂的鐘聲來丈量。
  - **核心原則**：像《深夜食堂》一樣的定點敘事。柳屋沒有壞人、沒有虐待案，也不做偵探式的家庭干預。心理師不負責「修理」孩子，而是陪伴（Keep company）——做那個「不需要孩子為了大人的安心而假裝沒事」的大人。
- **第一幕核心個案：芮恩（Wren，6 歲半）**：
  小學一年級，門牙有一顆正在搖晃。父母娜迪亞（Nadia，公立小學助教，住在黃色大門的老家）與班（Ben，木匠，八月剛搬到八個街區外麵包店樓上的綠色大門公寓）今年春天決定分居。
  - **大人的真相 vs. 孩子的信念**：父母的婚姻早已在兩年的經濟壓力與外婆心臟病中消磨殆盡；但今年三月的一個星期六早晨，芮恩為了哄難過的媽媽開心，爬上矮凳端茶，卻在廚房門口第三塊地磚摔碎了外婆留給媽媽的藍瓷茶杯，引發父母第一次當著她的面大聲爭吵。芮恩把整截斷落的藍瓷杯耳收進口袋，深信**是自己摔破杯子才讓一個家變成兩個家**。
- **第二幕核心個案：里歐（Leo，7 歲半）**：
  小學二年級，高個子、掉了一顆下門牙、總是踩著一條鬆脫的鞋帶。母親克萊兒（Claire，38 歲，牙醫診所洗牙師）與父親馬可斯（Marcus，40 歲，高中歷史老師兼籃球教練）。
  - **大人的真相 vs. 孩子的信念**：母親的父親亞瑟外公（Pop）患有長年心臟病，於十二月在睡夢中安詳離世。父母為了保護孩子，委婉告訴里歐「外公太老、太累了，所以去睡覺，然後沒有醒來」。七歲半的里歐從中建立了一套可怕而嚴密的字面邏輯：**太累 ＋ 閉上眼睛 ＝ 死掉**。看著下班後疲憊揉眼的母親與膝蓋喀喀作響的父親，他深信父母正在變老變累，於是把柳屋遊戲室變成「全體病患嚴禁躺下」的緊急診所，並在深夜拿著外公留下的米勒五金行紅色小手電筒，在爸媽房門口站崗兩秒看被子是否如常起伏。

## 3. 寫作核心準則與品質規範

1. **純艾拉第一人稱視角**：
   - 全書以艾拉的「我」為唯一視角。在會談室裡，她對孩子說的話極其簡短、平實（四到八個字的短句，只映照孩子的動作與話語，絕不說教）；但在內心獨白裡，她有著敏銳、溫厚且略帶自省的觀察。
2. **嚴禁心理學行話與直接命名情緒**：
   - 正文中絕不出現「創傷」、「防衛機制」、「分離焦慮」、「投射」、「共情」等臨床術語，也不直接寫「芮恩很內疚」、「她很難過」。
   - 一切情緒皆透過具體動作呈現：鞋尖對齊牆根、把玩具平分進兩個箱子、繞過地毯上的方格、摸比斯吉被咬扁的耳朵。
3. **標點與排版規範**：
   - **敘述句驚嘆號禁令**：除對白引號內極少數必要的語氣外，所有敘述句與描寫句句尾**嚴格禁止使用驚嘆號（！）**。
   - **分段分隔符**：全書一律使用 `***`，禁止使用 `---`。
   - **字體與語感**：全書採用台灣標準繁體中文，語感溫潤克制，兼具文學散文的細膩與輕小說的流暢閱讀節奏。

## 4. 第一卷全章節規劃

全卷共八章（序章、正文六章、終章），分為「深秋・芮恩篇」、「換季・過渡篇」與「隆冬・里歐篇」三大敘事弧：

| 章節 | 篇幅基準 | 核心意象與情節推進 |
| :--- | :--- | :--- |
| **序章：兩百遍的書** | ~2,800 字 | **賓州雷丁鎮的童年記憶 ＋ 費城十一月的早晨**。十歲的艾拉替三歲不語的弟弟丹尼用舊毛巾蓋住玩具架、並肩讀了兩百遍同一本繪本；39 歲的艾拉在老貓註腳的注視下摺好燕麥色布巾、收進「圖書館之友」帆布托特包，騎上丹尼組裝的單車前往柳屋。 |
| **第一章：柳樹下的紅手套** | ~3,500 字 | **會談前的柳屋巡禮與準備**。鎖好單車，透過鼠尾草綠大門玻璃看見提早十分鐘抵達的芮恩。與葛洛莉亞確認接送卡異常（星期四卻是爸爸班送來）。在走廊打開深綠帆布書衣的方格手帳（Hobonichi 式雙筆環扣合，左側夾層收納初談表、轉介信與作息表，巴川紙細方格內頁寫著會談紀錄），走進飄著烤吐司香的廚房折好四塊正方形蘇打餅乾與小柑橘，登上三樓閣樓圖書室選出《捧著鳥巢的小鳥》。 |
| **第二章：比斯吉的帆布包** | ~4,000 字 | **會談上半場：錯位的星期四、玩具箱與第一個祕密**。在候診室接住芮恩對黃綠方格時間表被打亂的不安。走進遊戲室、轉動洋梨計時器。芮恩跪在兩個玩具箱前把積木與動物平分成兩邊各十二個，詢問哪一箱是「星期二」（爸爸家的代稱）。在小圓桌上擺出小柑橘與四塊正方形餅乾；芮恩拉開比斯吉的帆布包清點小牙刷、筆記本與捲起的灰短襪，說出「這樣比斯吉就永遠不用把任何東西留在另一邊」。 |
| **第三章：不肯落地的鳥巢** | ~4,500 字 | **會談下半場與尾聲：繪本三停、藍瓷杯耳與後院台階**。蓋上燕麥色方布（「故事時間到了，玩具要睡覺囉」），點亮暖黃立燈共讀《捧著鳥巢的小鳥》。依序揭開第二個祕密（第一週沒人來接的雨天）、第三個祕密（貼著兔耳朵的悄悄話與一分鐘的沉默）、第四個祕密（解開灰短襪拿出整截藍瓷杯耳，說出三月星期六早晨摔破茶杯與兩個家的因果）。計時器輕響，芮恩畫下兩棵樹之間的鳥巢。媽媽娜迪亞接走芮恩後，艾拉在後院木台階坐滿五分鐘，收到娜迪亞說芮恩在車上哼起星期五老歌的簡訊，沾著袖口墨水寫下第三堂課筆記。 |
| **第四章：註腳先生的冬天** | ~4,000 字 | **換季過渡：艾拉的私人日常、朋友與雷丁鎮的電話**。十一月下旬至一月深冬。一房公寓裡暖氣管的輕響、17 歲老貓註腳的清晨呼嚕。與圖書館舊友梅芙、莎拉在義式小館的「星期四晚餐」，看見艾拉在成年同儕間乾冷溫厚的幽默；週日早晨與弟弟丹尼五分鐘極簡卻安定的通話（「後輪煞車皮，磨損了嗎？」）；一月在舊圖書館主持家長繪本工作坊，看見年輕父母被生活折騰的黑眼圈；換上新年度手帳巴川紙方格本，在二月四日寫下里歐的名字。冬雪降臨費城。 |
| **第五章：穿紅羽絨衣的醫生** | ~3,800 字 | **二月四日：融雪的柳屋、開診與不准躺下**。二月初融雪的泥濘清晨，艾拉在綠大門看見穿紅羽絨衣的小男孩在魚缸前敲玻璃「確認蝸牛是睡著還是卡住」。初談表上記錄著十二月病逝的外公，以及陳老師信中提到四次量心跳的紀錄。艾拉上樓取下磨損的動物籃（青蛙、貓頭鷹、小羊），三樓選定《守夜的小貓頭鷹》。進遊戲室後里歐宣布開診、任命艾拉為病歷護理師，並將三隻動物筆直立在踢腳板前（**祕密一【嚴禁躺下】**：「躺下病情只會惡化」）。 |
| **第六章：九十八度的蝴蝶餅乾** | ~4,200 字 | **體溫計、警告徵兆與普通累**。里歐要求補給，拿蝴蝶餅乾當體溫計塞進單眼青蛙嘴裡：「九十八度，他還是溫的」。翻開病歷紙背面記錄【警告徵兆】（**祕密二**）：貓頭鷹下班眼角的細紋、青蛙耳際的三根白頭髮（「她幫我綁鞋帶時我數過的」；「外公以前滿頭白髮，那叫醫生累，不是普通累」）。艾拉平實確認「普通累睡一覺就會好」，里歐鄭重拿綠蠟筆在紙上記下 `REGULAR TIRED`。 |
| **第七章：米勒五金行的小紅燈** | ~4,800 字 | **守夜的貓頭鷹、兩秒鐘的拇指光線與睡著的青蛙**。蓋上燕麥方布讀《守夜的小貓頭鷹》。第一停（樹枝巡邏）；第二停（里歐大喊「青蛙吞了一整輛消防車」製造警報逃避睡意）；艾拉接住鬧劇後，里歐說出**祕密三【我只是在閉目養神】**（外公叫救護車前一天的原話，丟樂高箱的恐懼）；第三停（老獾的解答，艾拉平實確認夜裡胸口是全自動起伏的，里歐在病歷寫下 `AUTOMATIC`）；**祕密四【米勒五金行的紅色手電筒】**（外公送的小手電筒，深夜在爸媽門口按兩秒看被子起伏）。計時器響起，青蛙終於被平放在布枕頭上（`SLEEPING. CHEST GOES AUTOMATIC. WILL WAKE UP.`）。 |
| **終章：門檻上的三根白髮** | ~2,500 字 | **候診室的鞋帶、後階落雪與二十分鐘的午睡**。克萊兒趕抵柳屋，蹲在玄關替里歐繫上鬆開的鞋帶，隨手將頭髮撥到耳後——黑髮中隱約露出的三根銀白髮絲被艾拉收進眼底（無聲的印證）。里歐揮手道別。艾拉在飄雪的後院木階坐滿五分鐘，收到克萊兒傳來「晚餐後在沙發上睡了二十分鐘，里歐替我蓋上毯子並把手電筒放在茶几上」的簡訊。艾拉在手帳寫下里歐的第二週筆記，二月的暮雪落滿窗外老垂柳。 |
