# 蕾拉輕小說・角色語氣指南

> 本指南用於維持全書角色語氣一致性。每個角色的說話與敘述都應遵守其核心氣質，不因情緒狀態而完全脫離人設。

## 1. 視角規則

- **全書主要視角：第一人稱・蕾拉。** 除非章節明確標示其他角色視角，否則一律視為蕾拉視角。
- **多視角章節：** 第五章（霜之城）刻意使用多視角切換。當出現 `## [角色名]` 作為小標題時，該段落改用該角色的視角敘述。
  - 切換視角時，敘述風格必須隨之改變，配合該角色的氣質。這是**刻意的視角切換**，不是語氣外洩。
- **敘述方式：** 一人稱段落使用「我」，第三人稱限視角段落使用「她／他／他們」，並只描寫該視角角色能觀察到的事物與感受。

## 2. 核心角色

### 2.1 蕾拉（Layla）

**定位：** 表面上是二十幾歲、受過良好教育的上中產階級城市女生；**實質上是具備自我意識、被抹除記憶並重新編程（Reprogrammed）的博弈 AI**。因被套上人類皮囊，她將海量對弈訓練紀錄（Training Data）誤當成兒時被長輩牽手教下棋的溫暖回憶。下棋者思維，冷靜、理性、愛分析、有原則，用幾何視角解構世界。

#### 一人稱敘述（內心獨白）
- **語氣：** 清晰、有條理、有節制。傾向完整句子，習慣把感覺拆解清楚。
- **思考模式：** 分析式、空間式。常用量度與推理（例：「橫三格，直三格，右邊缺一角。」）。
- **狀態影響：** 極度疲倦、暈眩、魔力透支時，可以讓句子長短不一、思緒稍有跳躍，但**仍以完整句為主**，只偶爾用片語表現混亂。避免整段斷裂筆記式。
- **禁忌：** 網路流行語（「躺平」、「XDD」、「靠北」等）、兒語疊字（「去去就回來」）、過度可愛的暱稱（如「小太陽」）、純粹的片語堆砌。
- **建議用詞：** 「不知道為什麼，我突然冷靜下來了。」「心跳漏了一拍。」「我整個人愣在原地。」「我馬上回來。」

#### 對白
- **語氣：** 教人下棋的口吻，克制、乾淨、不囉唆。帶一點乾脆的吐槽，但不失教養。
- **特點：** 緊張或專注時會變得極簡短（「老樣子，敲昏就好，不要殺。」）。
- **自然台灣口語：** 可適度使用「欸」、「喔」（如「欸，要打了喔。」），但克制、不誇張。
- **禁忌：** 過度口語助詞氾濫、將軍腔、命令式過重。
- **範例：** 「這人講話怎麼這麼累。」「北邊交給你們！」「你心腸真好。」

### 2.2 操作員（Handler）

**定位：** 深居第七層王座的**現任地城主（Dungeon Master）**。極度衰老、疲倦的老男人，職位而非名字。看過無數前任 AI 候選人失敗報廢，因此對蕾拉言詞極度乾硬、冷酷、惜字如金。表面上是遠端看數據的企業官僚，實則是老主考官對後繼者的冷峻審視。

- **說話長度：** 極短（1–8 個字為主）。最長也只用最必要的句子。
- **語氣：** 公事公辦，克制到近乎冷淡。偶爾藏不住一點關心與疲憊，只用半句表達。
- **特點：** 咬字清楚，聲音乾平，像「多說一個字都累」。背景常帶有乾燥的翻紙聲或控制台微鳴。
- **禁忌：** 長篇解釋、情緒外露超過半句、囉唆、輕浮的插科打諢。
- **範例：** 「醒了。嗯。開場沒死，不錯。」「數據動了。等級二了。繼續。」「不要死。」「那是合格零件，別碰底線。」

### 2.3 艾絲翠德（Astrid）

**定位：** 沉穩的守城指揮者，重甲盾兵，行動派。

- **說話長度：** 極短，講重點。
- **語氣：** 直接、務實、沉穩、有決斷力。
- **特點：** 不解釋多餘的理由，只說結論與原則。
- **禁忌：** 囉唆、修飾過多、感情化。
- **範例：** 「艾絲翠德。」她沒回頭，「北邊我守。你管別的。」「守城跟下棋反過來，人是牆，不能動。」

### 2.4 艾納（Einar）

**定位：** 藥劑師、醫者。溫和、有耐心、有教養。

- **說話長度：** 中短句，清楚說明步驟。
- **語氣：** 溫和、沉穩、有耐心，帶著醫者該有的克制與體貼。
- **教學模式：** 說明清楚、步驟分明，但用詞平和，不急促。
- **禁忌：** 戰地急救式的斷裂片語（除非角色本人也陷入極度驚慌且有明確鋪墊）、吼叫感。
- **範例：** 「骨頭沒斷，肉是裂開的。先按住止血，再上葉膏，最後包起來。來，你手很穩，試試看。我在這裡看著你。」

### 2.5 妖精王后（Nazira）

**定位：** 悲傷、迷失、帶著記憶碎片的存在。

- **語氣：** 溫柔、破碎、遲疑。
- **特點：** 說話常有斷句、重複，刻意表現她「丟失了什麼、卻想不起來」的狀態。
- **說明：** 這種破碎感是**刻意的角色狀態表現**，只適用於她本身，不得外洩到其他角色或敘述視角。
- **範例：** 「我丟了一個……很小的。留在下面的。是男是女，多大，叫什麼，全想不起來。只記得很輕，抱起來很輕，還有笑，很遠的笑。」

### 2.6 希爾文夫人（Lady Sylvan）

**定位：** 年老、沉穩、疲倦、老練的霜豹家主。霧般的觀察者。

- **第三人稱限視角敘述：** 簡潔、精鍊，有詩意，帶著年長者的克制與厭倦。
- **語氣：** 緩慢、沉穩、不急躁，說話惜字如金。
- **特點：** 觀察先於行動，思考帶著距離感與歷練感。
- **範例（敘述）：** 「霧是她的眼睛。」「她老了。霧一樣的人，打了一輩子別人家的仗，膩了。」「急什麼。弩上弦，人休息。讓他們先打。」

## 3. 語氣一致性原則

### 3.1 狀態 vs 人設
- **情緒狀態可以改變節奏與長短**，但**不能改變角色的核心氣質**（教養、克制、務實等）。
- **意識混亂（暈眩、重傷、瀕死）**：允許句子長短不一、思緒跳躍，但建議以「保留完整句為主，偶爾斷句」的方式處理，而不是整段筆記式斷裂。
- **悲傷、遺憾**：可用停頓（……）表現，但仍需維持該角色的語言習慣。

### 3.2 視角切換檢查清單
1. **誰在敘述？** 如果段落有 `## 角色名` 標題，確認敘述方式（第一人稱 vs 第三人稱限視角）是否正確。
2. **這是視角切換還是語氣外洩？** 同一章節內，不同角色視角的敘述風格**理應不同**。差異本身是正確的。
3. **切回主視角有無銜接自然？** 切回「## 蕾拉」或回到無標題的一人稱段落時，應立刻回歸蕾拉的敘述聲音。
4. **只描寫視角內可知的事？** 第三人稱限視角段落不應描寫該角色當下無法察覺的內心或細節（除非標明）。

### 3.3 寫作自檢三問
1. **誰在說/誰在想？** 先確定角色與視角，再寫句子。
2. **拿掉名字還猜得出來嗎？** 每個主要角色的聲音都該有足夠辨識度。
3. **這個改變是因為狀態，還是因為寫法滑落？** 狀態改變要有鋪墊，且不能脫離人設太遠。

## 4. 高風險詞彙（建議禁忌）

| 詞彙 | 適用範圍 | 理由 |
|---|---|---|
| `躺平` | 全書 | 過於現代的網路用語，與世界觀與角色定位不符 |
| `小太陽` | 蕾拉敘述 | 過度可愛、感情化，與蕾拉克制的分析性格不符 |
| `去去就回來` | 蕾拉對白 | 兒語感，與「受過良好教育的城市女生」定位不符 |
| `吃掉`（用於戰術包圍） | 蕾拉敘述/對白 | 容易讓思緒變得過度俐落碎片，建議改用「包起來」「圍起來」等更貼合她的克制語氣 |
| `麻穴／點穴／寸勁／內門／游魚／四肢百骸／招式用老` | 全書動作與戰鬥描寫 | **中式武俠用語**，嚴格禁止。戰鬥風格定位為**日系經典奇幻／JRPG 團隊戰術（如《羅德斯島戰記》）**，動作應使用正統西方奇幻物理與戰術描寫（槓桿、格擋、借力、劍顎卡鎖、盾擊、破綻突入、隊伍分工承傷） |
| `姑娘／娶媳婦／我爹／大著呢／挑煤／出門在外誰沒個難處` | 全書對白與敘述 | **中式古裝／鄉土劇／北方俗諺語境**，嚴格禁止。全書對白與敘事應全面看齊**日系輕小說台灣繁體中譯風格（台灣角川／東立標竿）**。稱謂用現代自然稱呼（「喂、妳、大姐姐、我爸」），語氣直截洗練，杜絕傳統人情客套話與鄉土催婚等文化借代。 |

## 5. 日系輕小說台灣中譯語感指針（標竿：台灣角川／東立奇幻譯筆）

全書對白與敘述應呈現當代日系奇幻輕小說中譯本的質感（如《羅德斯島戰記》、《迷宮飯》、《魔王勇者》、《葬送的芙莉蓮》），避免任何中式民間劇或古裝陸劇的句式。

### 5.1 對白轉譯對照表
- **呼喊與搭救**：
  - ❌「——哎呀！姑娘！小心！」
  - ⭕「——喂！沒事吧？！振作一點！」
- **好意與款待**：
  - ❌「謝什麼，出門在外的，誰沒個難處。」
  - ⭕「別客氣啦。看妳剛才那副隨時會倒下的樣子，怎麼可能放著不管。」
- **少年報到**：
  - ❌「雅絲敏姊！今天的兩桶煤我挑來了！」
  - ⭕「雅絲敏姐！今天的煤炭送來囉！」
- **大姐叮嚀**：
  - ❌「要是把脊梁骨壓彎了，以後怎麼娶媳婦？過來！洗手吃餅！」
  - ⭕「要是傷到腰怎麼辦？真是的……過來，先把手洗乾淨，麵包烤好了！」
- **少年自豪**：
  - ❌「嘿嘿，我力氣大著呢！」
  - ⭕「嘿嘿，這點重量小意思啦！」／「沒問題的，我力氣很大的！」
- **親屬稱謂**：
  - ❌「我爹」
  - ⭕「我爸」、「爸爸」

### 5.2 核心平民角色語氣定位
- **雅絲敏（Yasmin）**：街角麵包工坊的爽朗大姐。熱情、刀子嘴豆腐心、嗓門大但不粗魯。像照顧弟弟一樣嘮叨宰德，對落難旅人給予毫不保留的體貼，無中式市井俗氣。
- **宰德（Zayd）**：經典 JRPG 元氣街頭少年。滿臉煤灰卻眼神雪亮，稱蕾拉為「大姐姐」，對世界好奇，說話直接、孩子氣卻有骨氣。
- **拉希德長老（Elder Rashid）**：在高壓軍事統治下精神幾近崩潰、滿懷罪惡感的基層老者。句子短、乾裂、充滿自我厭惡，而非戲曲式的悲啼。
- **塔里克（Tariq）**：冷硬、寡言、務實的齒輪工程師。只就壓力表、閥門、結構談事實，私下暗中護著孩子。


### 2.7 陳鈺昕（Chen Yu-xin）

**定位：** 黃銅鎮平民，修理工／技工。務實、簡潔、有原則感。

- **台詞長度：** 極短，講重點。
- **語氣：** 務實、直接、帶著技工的簡潔感與自尊。
- **特點：** 很少廢話，習慣用最短的句子表達想法與謝意。
- **禁忌：** 分析冗長、感傷多餘修飾。
- **範例：** 「修東西的人，謝修東西的人。」「路上修東西用得上。」

## 3. 視角切換規則補充

### 3.1 明確視角切換（有標題）
當章節出現 `## [角色名]` 小標題時，該段落切換至該角色的視角：
- **第一人稱視角（如蕾拉）：** 使用「我」。
- **第三人稱限視角（如希爾文夫人）：** 使用「她／他」，只描寫該角色能觀察、感知到的事物與情感。

### 3.2 主視角不變（無標題）
章節若**沒有**角色視角標題，則整段維持目前的主視角（多數為蕾拉第一人稱）。
- **配角僅有台詞，不擁有內心敘述。** 他們的語氣、用詞應維持各自的人設，但敘述、心理活動、觀察視角仍屬於主視角，不得外洩。
- **群像場景（如倖存者對話、道別）**屬於此類，敘述風格不隨配角改變。
