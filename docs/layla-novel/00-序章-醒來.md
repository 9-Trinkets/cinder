# 序章：醒來

我醒來的時候，背很痛。

不是那種睡太久的痠，是石頭頂著脊椎，一節一節，冷氣從縫裡爬進衣服的那種痛。

我睜開眼睛。

天花板很低。黑色的石頭，裂縫裡卡著灰。空氣聞起來有土味，還有煙，很舊的煙，像是很久以前有人在這裡生過火，味道洗不掉了。

然後我發現，我旁邊有一個人。

不對。不是人。

它很大，坐在牆邊，一動也不動。石頭做的身體，關節的地方有白色的刻痕，手掌大得可以蓋住我的臉。

眼睛是兩顆嵌進去的圓石頭，沒有光，可是我就是覺得——它在看我。

我嚇了一跳，整個人往後縮。背撞到牆，痛得我差點沒喘過氣。

奇怪的是，我沒有尖叫。

我的身體比我的腦袋快。它自己縮起來，自己護住脖子，自己把重心壓低，腳尖點地，隨時可以往旁邊閃。

等我反應過來，我已經擺好姿勢了。

……我會戰鬥？

我連我是誰都想不起來，身體卻記得怎麼戰鬥。這什麼道理。

「嗨。」我試著發出聲音，「那個……你會動嗎？」

它沒有回答。

當然。它是石頭。我幹嘛問石頭問題。

我低頭看自己的手。右手握著一個東西，握得很緊，緊到指節都白了。

是一支粉筆。

不，說是粉筆也不太對。它比粉筆粗，比粉筆重，拿起來溫溫的，表面有一層淡淡的光，像是螢光棒快沒電的那種亮度。灰白色的，摸起來有點暖。

我叫什麼名字？

我想了三秒。

蕾拉。

只有這個。只有「蕾拉」兩個字，像一張被撕到只剩角角的紙。

我幾歲？從哪裡來？為什麼會睡在這裡？我爸媽是誰？我有沒有朋友？

全部空白。

牆壁。牆壁應該知道吧。我轉頭看，牆上什麼都沒有，只有水痕。地上有灰，灰上有痕跡。

等等。

我蹲下來。

地上有線。很淺很淺的溝，像是很多人、很多年，一直走同一條路，走出來的凹痕。一條橫的，一條直的，交叉成直角。

再過去，還有一條。再一條。

橫的跟直的。直的跟橫的。整個房間的地板，被這些線切成一格一格的。

我的手指自己動了。沿著那條線，輕輕劃過去。

好熟悉。

熟悉到我的心跳漏了一拍。

「……我走過這裡？」

沒有人回答我。只有水滴聲。啪。啪。很遠的地方，還有一種規律的聲音——叩……叩……像是有人拿棍子，慢慢敲石頭。

叩……叩……

我的心跳跟著那個聲音走。不知道為什麼，我突然冷靜下來了。

好，冷靜。先整理現況。這是我不知道從哪裡學來的習慣：慌也沒用，先數。

一，石頭房間，沒有門，只有一個黑黑的通道往外。

二，一個石魔像，坐在牆邊，不動，不說話。

三、一支會發光的粉筆，在我手上。

四、我，蕾拉，其他什麼都不記得。

五，肚子有點餓。腳踝有舊傷，走路會有一點卡。左手小指彎彎的，以前斷過。

……連舊傷都記得，就是不記得人生。也太好笑了。

就在這個時候，空氣裡響起聲音。

滋——滋滋——

像是收音機轉台。那個聲音直接出現在我腦袋旁邊，嚇得我差點把粉筆丟出去。

「——聽得到嗎。」

老男人的聲音，又乾又平，像很久沒好好睡過。咬字很清楚，但是沒什麼力氣，好像多說一個字都累。

「醒了。嗯。開場沒死，不錯。」

我環顧四周。沒有喇叭。沒有人。

「誰？」

「操作員。」他說，「在上面，看著你的數據。」

數據？

「你在哪裡？」我問，「這裡是什麼地方？」

對方停了一秒。滋滋聲裡，有紙張翻動的聲音。

「你在一個洞窟裡。深，很深。下面還有很多層。你的工作很簡單：學會規則，走下去。」

「什麼規則？」

「自己找。又不是旅行團。」他說，「喔，對了。提醒你一件事。」

「什麼事？」

「不要死。」

滋——。聲音斷了。

……這人講話怎麼這麼累。

我坐在地上，瞪著空氣看了五秒。然後我決定把那個沒禮貌的聲音先放到一邊。因為比起他，有一件事更讓我在意。

我的手。

我的右手，從剛才開始，就一直在動。

它握著那支粉筆，懸在地板上方，微微發抖。不是害怕的那種抖，是……想寫什麼，卻想不起來的那種抖。

筆尖的光，亮了一點。

我吞了一口口水，把粉筆壓下去，沿著地上那條舊舊的凹痕，輕輕拖過去。

粉筆劃過石頭，發出很細的聲音。沙——。

光留下來了。

一條淡淡的、白色的線，浮在地板上，像是被點亮的傷口。跟牆邊那個石魔像關節上的刻痕，一模一樣。

我的手停不下來。

轉彎。再轉彎。我的肩膀自己用力，手腕自己轉。我畫了一個圈。一個歪歪的、不完美的圈。

可是當最後一筆接起來的時候——

嗡。

整個圈亮了起來。

光很暖。從地板底下透上來，照亮我的臉，照亮那個石魔像的腳。

石魔像的腳，動了一下。

很小很小的一下。像是睡覺的人，被光照到，腳趾縮了一下。

我整個人愣在原地。

然後，我笑了。不知道為什麼，就是想笑。眼淚差點掉下來。

「……我會這個。」我小聲說，「我會畫這個。我以前畫過。」

叩……叩……遠方的敲石聲，還在繼續。

我站起來，把粉筆握緊。腳踝的舊傷抽了一下，但是沒關係，我知道怎麼站才不會痛。身體記得。身體什麼都記得，只有我不記得。

沒關係。那就一條一條學回來。

地上有格子。牆上有水痕。前面有通道，吹來風，帶著煙跟肉的味道。有人在前面生火，有人在前面走路，有人在前面等我。

我數了數地上的格子。橫三格，直三格，右邊缺一角。

很好。是棋盤。雖然我還不知道這是什麼棋。

「喂，石頭。」我對牆邊的魔像說，「走吧。去找出口。」

它沒有回答。但是這一次，我覺得它的眼睛，好像亮了一點點。

我踏出第一步。

石頭很冷。粉筆很暖。我的影子被圈的光拉得很長，貼在牆上，像另一個我，跟著我一起走。

——開始了。
