# 第八章 暴風雪前哨

風雪穿透箭垛的縫隙，在長廊的石面上刮出一層白霜。

要塞北面，通往霜狼家莊園的鐵索吊橋在狂風中劇烈搖晃。橋面覆蓋著厚厚的黑冰，兩側的粗鐵鏈被凍得梆硬，隨著風勢發出刺耳的呻吟。

我站在北口長廊的石台後方，雙手握著石鑿斧，視線緊盯著吊橋對岸的松林。

視力增強器的鏡片泛著微弱的光暈。在風雪遮蔽的視野中，十幾道移動的暗影正沿著橋面疾步前推。

那是霜狼家的先遣隊。

大約十五名身披深灰色狼皮短甲的斥候，手持圓盾與破甲短矛，步伐輕盈而迅捷。在他們前方，四頭體型碩大、皮毛厚實的雪原獵犬正壓低身形，腳爪在冰面上抓出細碎的白痕，無聲地逼近要塞大門。

「獵犬在前，輕裝在後。」

艾絲翠德就擋在我前方兩步的窄口處。她將那面厚重的生鐵塔盾往地面重重一頓，盾牌底部的鋼角生生鑿裂了石面，死死嵌進地縫之中：

「霜狼家習慣用獵犬衝散防線，逼守軍露出破綻，隨後短矛突刺。不要慌，把牠們放進三公尺內。」

「艾爾溫。」我側過頭，低聲看向後方的石階。

精靈副官艾爾溫單膝跪在石階高處，身後的四名精靈弓手早已將漆黑的木弓拉至半滿，箭尖向下微垂，避開呼嘯的逆風。

「精靈的箭不會在風中失準，蕾拉小姐。」艾爾溫平靜地回應，「只要目標進入走廊，牠們就過不來。」

吊橋上傳來一陣尖銳的口哨聲。

四頭雪原獵犬猛然蹬地加速，身形化作四道貼地的灰影，伴隨著冰屑飛濺，朝著窄小的走廊入口猛撲而來。

「放。」

艾爾溫的聲音極其冷靜。

崩、崩、崩。

四道深綠色的箭影撕裂風雪，精準地越過艾絲翠德的頭頂，自狹窄的夾角向下俯衝。

第一頭獵犬在騰空的瞬間被兩支木箭同時貫穿咽喉與前胸，重達百磅的身軀被衝擊力生生釘在冰面上，滑出數公尺遠。另一頭獵犬試圖從側壁跳躍，卻在半空中被第三支箭射穿了後腿關節，哀鳴著翻滾跌落。

然而剩下的兩頭獵犬已經衝進了走廊。

牠們張開獠牙，猩紅的長舌在冷風中甩動，徑直撲向艾絲翠德的喉嚨與盾牌下緣。

艾絲翠德沒有退後半步。

她右手緊握寬刃長劍，沉腰發力，塔盾的鋼面如同一面直立的鐵壁，向前重重一迎。

沉悶的撞擊聲迴盪在走廊裡。

撲向盾牌的獵犬被反震的巨力撞得骨骼發出悶響，倒飛出去。而撲向右側空檔的另一頭，則被艾絲翠德反手一劍斬斷了頸椎，乾脆俐落地滾落在地。

「第一波只是試探。」

艾絲翠德甩掉劍尖上的血沫，視線越過倒下的獵犬，看向已經踏上要塞石階的霜狼斥候：

「他們要上來了。」

十五名斥候舉起圓盾，組成密集的三角陣型，短矛從盾牌縫隙中探出，踏著同伴與獵犬的屍體，朝著窄口發起齊衝。

我深吸一口氣，目光迅速掃過階梯的寬度與角度。這條走廊只有三公尺寬，只要把空間鎖死，人數優勢就毫無意義。

「前排魔像，交錯閉鎖。」我低聲下令。

兩尊身形魁梧的黑石魔像轟然上前，以千鈞之重橫擋在艾絲翠德兩側，玄武岩手臂如鐵欄杆般相互扣合，硬生生將寬達三公尺的走廊擠縮成不到一公尺的死角。

鐺、鐺、鐺。

數柄生鐵短矛狠狠刺在黑石魔像的胸口，迸發出一連串火星。魔像的花崗岩外殼紋絲不動，甚至沒有留下明顯的凹痕。

站在後方的白石魔像隨即探出巨大的石掌，越過黑石防線，如鐵鉗般精準地扣住兩柄短矛的矛桿，向前猛力一拽。

兩名霜狼斥候腳下打滑，重心失控向前傾倒。

艾絲翠德的長劍隨即化作一道冷冽的弧光，精準地刺入對方的板甲縫隙。

走廊前端瞬間化作絞磨的窄道。精靈弓手的箭矢從上方不斷傾瀉，每一箭都精準地找尋著肩甲與護頸之間的空隙；黑石魔像穩如磐石地頂住衝撞，白石魔像則以驚人的力量逐一奪下武器。

短短三分鐘內，七名斥候倒在階梯上。

剩下的霜狼士兵察覺到這座隘口根本無法強行突破，終於發出一聲驚恐的呼哨，拖著傷員向後退去，迅速縮回了吊橋對岸的風雪之中。

### 霜狼先鋒隊長

「退！退回橋頭！」

我扯著嘶啞的嗓子咆哮，一邊用圓盾擋開從城頭射下的一支冷箭，一邊連滾帶帶爬地退過結冰的鐵索吊橋。

吊橋在暴風雪中瘋狂搖擺。

腳下的木板覆滿黑冰，每跑一步，靴底的防滑鐵齒都在冰面上打滑。

我們出發時是整整十五名精選的霜狼斥候，外加四頭用生肉餵養的雪原戰犬。我們曾用這套戰術在暴風雪裡生生撕碎過三支叛軍商隊。

但現在，活著退回松林邊界的，只剩下六個人。

戰犬全死了。

「隊長……那到底是什麼東西？」身旁的副手整條右臂都在淌血，破甲短矛早就不知道丟在哪裡，臉色白得像死人一樣，「要塞裡關的不是一批該送進聖堂的殘次祭品嗎？為什麼會有精靈弓手？還有那些石頭……那些根本打不動的石像！」

「閉嘴！」我喘著粗氣，一把扯下被箭矢擦破的狼皮兜帽。

狂暴的冷風灌進領口，但我背後的冷汗卻止不住地往外冒。

我回頭望向那座矗立在風雪中的要塞北門。

在那道狹窄的石砌隘口前，一尊身披重型板甲的高大女戰士冷冷地站在階梯頂端，手中的生鐵塔盾滿是刀痕；而在她身旁，兩尊黑沉沈的巨石魔像宛如兩座永遠無法撼動的黑色懸崖。

在魔像後方，站著一名身形纖細的黑髮少女。

她的皮膚微褐，墨黑色的眼眸在風雪中冷靜得讓人發毛，彷彿剛才那場短兵相接的血戰，在她眼中只是一次毫無波瀾的演練。

「隊長，大營那邊來人了。」

身後的松林中傳來沉重的踩雪聲。

一隊身穿厚重青銅護胸甲、腰懸短柄戰斧的鐵羊家士兵大步走出林線。領頭的是鐵羊家的副官，那個滿臉絡腮鬍、渾身散發著機油焦味的矮壯男人。

「哎呀，這不是霜狼家引以為傲的雪原獵犬嗎？」

鐵羊副官停下腳步，掃了一眼我們狼狽的隊伍，嘴角咧開一抹毫不掩飾的譏諷：

「怎麼連一扇破要塞的偏門都沒摸到，就被幾隻看門狗咬得落荒而逃？你們那套打獵的把戲，看來只配在深山裡追兔子。」

「少說風涼話！」我咬著牙，握緊了腰間的短劍，「裡面根本不是普通的逃犯！有精準度極高的精靈射手，還有至少四尊重型石魔像！你們要是走北門，下場跟我們一樣！」

「石魔像？精靈？」

鐵羊副官像是聽到了天大的笑話，重重往地上吐了口濃痰：

「聖堂把這座要塞交給三家處置，誰先拿下叛亂首領的人頭，誰就能拿到前往上層聖域的通行許可。我家大人可沒打算像你們一樣在橋上玩雜耍。」

他轉過身，粗暴地朝著林地深處招了招手：

「把傢伙推出來！讓這些玩狗的鄉巴佬看看，什麼才叫真正的攻城！」

雪沫翻滾。

伴隨著沉重而低沉的金屬履帶碾壓聲，一台龐大而猙獰的鋼鐵巨獸緩緩穿過松林。

那是鐵羊家的蒸汽破城車。

六條寬大的生鐵履帶在雪地上碾出深深的泥溝，車身兩側包裹著厚實的鉚接鋼板，車頂巨大的圓柱形鍋爐正向著灰暗的天空噴吐著滾滾黑煙。而在車身最前方，一根直徑超過半公尺、通體由生鐵鑄造的破城衝槌，正如巨獸的獠牙般向前探出。

「東南側的水道閘門年久失修，那是這座要塞唯一的弱點。」

鐵羊副官跨上一台輕型蒸汽拖車，回頭冷笑著看了我一眼：

「看好了，霜狼的崽子。等我們的衝槌把閘門砸成廢鐵，裡面的石頭腦袋會被生生碾成粉末！」

鋼鐵履帶隆隆作響，朝著要塞東南側的下坡路推進。

我看著那台噴吐黑煙的怪物，後頸的寒毛卻不知為何根根立起。

那個站在隘口石階上、擁有黑色眼眸的少女……她真的會留出這麼明顯的致命破綻給鐵羊家嗎？

### 鐵羊破城隊長

「加煤！把壓力指針給我頂進紅線區！」

破城車的操作艙裡熱得像個蒸籠，機油燒焦的刺鼻臭味混雜著劣質煤炭的黑煙，燻得人眼睛生疼。

我抹了一把臉上的黑汗，雙手死死把住轉向液壓閥。

齒輪箱在腳下發出尖銳而刺耳的咬合聲，六條履帶生生碾碎了要塞外圍的木柵欄，帶著整整四噸重的鋼鐵身軀，一路衝進了東南側水道外圍的低窪石道。

穿過排氣管的縫隙，我看到了前方的目標。

那是一扇高約三公尺、原本用來阻擋地底山洪的厚厚生鐵閘門。門框四周的花崗岩早就被潮氣侵蝕得斑駁不堪，兩側的滑軌上掛著一層黑黃色的鐵鏽。

「這群蠢貨以為把北門堵死就能高枕無憂了！」

坐在鍋爐旁的副手興奮地咧嘴大笑：

「這扇水閘門連個護城壕都沒有！只要三錘，裡面的傳動軸就會被直接震碎！」

「準備撞擊！」

我一把推開液壓離合手柄，沉重的破城車在距離閘門五公尺處猛然剎住。

高壓蒸汽瞬間倒灌進主活塞。

前端那根重達千斤的生鐵衝槌在鋼索與活塞的雙重帶動下，帶著尖銳的呼嘯聲向後拉緊，隨後——

轟隆——

第一錘狠狠砸在生鐵閘門的正中央。

整扇鐵門發出一聲恐怖的呻吟，門心的生鐵板硬生生被砸出了一個巨大的凹坑，大塊大塊的花崗岩碎屑從門樑上方崩落。

「哈哈！看到沒有！」副手狂笑著拉動回位桿，「再來兩次，門就徹底塌了！」

轟隆——

第二錘接踵而至。

這一次，伴隨著生鐵撕裂的刺耳尖響，閘門頂部的固定生鐵插銷發出一聲清脆的斷裂聲，整根斷銷帶著火星從門縫中崩飛出去。

厚重的閘門向內劇烈凹陷，門框與牆壁之間生生被撕開了一道將近一公尺寬的巨大裂口。

透過這道裂口，我能清楚地看到要塞內部的庭院。

裡面沒有重裝部隊，只有一個握著管鉗、滿身油污的黑髮平民女人，以及一個身穿灰白長袍、神色慌亂的年輕醫者。

「破了！門開了！」

跟隨在破城車兩側的八名重裝步兵拔出了蒸汽動力錘，眼中閃爍著嗜血的光芒：

「最後加壓一次！把門撞倒，衝進去殺光他們！」

「全壓釋放！」

我怒吼著，將鍋爐的排氣閥徹底關死，將所有的蒸汽壓力灌注進主衝程。

粗壯的生鐵衝槌帶著毀天滅地的慣性，撕裂空氣，第三次朝著裂口深處悍然轟出。

然而，就在衝槌即將砸穿殘破閘門的同一瞬間——

一道沉重如山岩的漆黑巨影，毫無預兆地直接從內側跨進了裂口。

那不是人。

那是一尊通體由純黑玄武岩構成、高達兩公尺以上的巨大石像。

它沒有躲閃，沒有後退。

它就那樣直直地站在門框的正中心，用寬厚平整的石質胸膛，迎面撞上了那根呼嘯而至的鑄鐵衝槌。

它是瘋了嗎？

用石頭去擋四噸重、全速衝刺的蒸汽破城槌？

下一秒，沉悶如雷霆在地底引爆的撞擊聲，在整座水道走廊中炸裂開來。

當——

反震的狂暴衝擊力甚至順著鋼架倒灌進了操作室，震得我眼冒金星，儀表盤上的玻璃片寸寸碎裂。

我難以置信地透過瞭望窗望去。

衝槌停住了。

那尊黑石魔像竟然沒有被砸成碎屑。

它的雙腳深深陷入了地面的石板之中，將堅硬的花崗岩犁出了兩道半尺深的溝壑；它的雙手死死扣住了兩側開裂的門柱，硬生生用自己的脊樑與胸膛，將這記足以破開城門的重擊正面吃了下來。

「怎麼可能……」副手臉色慘白，手裡的煤鏟掉在地上。

黑石魔像的胸口浮現出無數道發白的碎紋，石屑如雨水般落下。

但它那雙泛著金色微光的眼眶，依舊死死盯著前方，半步未退。

「加壓！快加壓！把它給我碾成灰！」

我發瘋般推動操縱桿，液壓活塞發出野獸般的尖銳哀鳴，不顧一切地向前二次推擠。

哢嚓。

碎裂的脆響終於響起。

在兩股毀滅性的力量擠壓下，黑石魔像的胸口徹底崩解，漫天的灰色石屑如同濃霧般爆開。

然而，就在它身軀碎裂的最後一刻，那兩隻粗壯的岩石斷臂依然緊緊扣著門柱，崩塌下來的重達千斤的石塊，連同原本變形的鐵閘門，死死卡進了破城槌與前輪的滑軌之間。

破城槌被卡死了。

「該死！動不了了！倒車！快倒車！」

我拼命拉扯倒車離合器，但傳動軸傳來一陣刺耳的金屬崩斷聲。

透過煙霧，一根手臂粗細的生鐵撬棍不知何時已經被那個黑髮女人狠狠插進了破城車暴露的一號傳動齒輪裡，將整個齒輪箱絞成了一團廢鐵。

緊接著，上方傳來了急促而冷冽的破空聲。

幾道帶著綠色微光的木箭精準無比地穿透了車側步兵的面罩縫隙。

伴隨著一聲憤怒的長嘯，剛才守在北門的那名金色麻花辮女戰士，手持滴血的重劍，如狂怒的風暴般衝進了缺口。

「撤退！快棄車撤退！」

我踹開變形的操作室鐵門，在濃煙與蒸汽中連滾帶帶爬地逃出水道。

當我回頭最後看了一眼那座被石塊死死堵住的閘門時，只看到那個墨黑長髮的少女，正安靜地蹲在那堆崩解的灰色碎石前。

她的背影那麼單薄，卻讓我感到一種深入骨髓的戰慄。

我們惹錯了對手。

### 蕾拉

蒸汽的白霧在寒風中漸漸散去。

水道閘門被坍塌的花崗岩、碎裂的生鐵板與癱瘓的破城車死死封死。

艾絲翠德帶著幾名精靈戰士在缺口處架起了重型拒馬，艾納正跪在地上，熟練地替陳鈺昕包紮被鐵鏽擦傷的手背。

沒有人說話。

空氣裡只有冷卻水滴落在滾燙鐵皮上的滋滋聲。

我蹲在門前的碎石堆邊，慢慢伸出手，指尖觸碰到的是一片冰冷的石粉。

那是它的核心碎片。

從第一層幽暗冰冷的哥布林洞窟，到第二層危險密集的地下森林，再到第三層熾熱的熔岩大釜……

它從來沒有發出過聲音，也沒有任何抱怨。

每當危險降臨，這具厚重的黑石軀體總是在第一時間橫擋在我的身前。它是我計算防線時最可靠的基石，也是我醒來後這個陌生世界裡，最早陪伴我的同伴。

現在，這具石質的軀殼徹底化作了塵埃。

精神深處那根微弱的引導絲線，斷掉了。

掛在腰間的宰德提燈，在此刻輕輕震顫了一下。

燈芯中那團溫潤純淨的微光微微擴散開來，柔和地籠罩在石粉之上，彷彿是在為一個沉默而忠誠的靈魂無聲悼念。

我閉上眼睛，將那抹突如其來的酸楚壓回心底。

「蕾拉小姐。」

身後傳來陳鈺昕帶著一絲沙啞的聲音。

她擦掉臉上的機油，看著地上的碎石，嘴唇微顫：

「對不起……如果我的齒輪卡得再快一點……」

「這不是妳的錯，鈺昕。」

我站起身，將手掌上的灰色石粉輕輕拍落。

當我睜開雙眼時，眸底的墨黑色已經重新化作了冰雪般的冷靜：

「它履行了守衛的職責。而我們，必須守住這座要塞。」

咚——

遠方的地平線上，一聲雄渾而悠長的號角聲穿透了漫天的狂風暴雪。

那是一聲淒厲悠長的狼嚎。

緊接著，第二聲號角在東面的山脊上轟然炸響，那是如鐵錘砸擊巨砧般沉重刺耳的金屬轟鳴。

隨後，第三聲高亢尖銳、宛如夜梟嘶鳴的長號，自南面的密林上方呼嘯而起。

三聲號角在要塞上空匯聚、迴盪，震得箭垛上的積雪撲簌落下。

艾絲翠德快步走回中庭，深灰色的眼眸望向昏暗的天際，握著劍柄的手指因為用力而關節發白：

「霜狼家、鐵羊家、宵梟家……剛才的都只是先遣隊。」

「三家的領主……主力部隊全部到了。」

在呼嘯的暴風雪平原邊緣，無數面旗幟在風中獵獵作響。

真正的圍城，現在才要開始。
