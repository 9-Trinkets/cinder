# 第三章：火之間

梯子還沒爬完，熱氣就上來了。

不是暖，是燙。像把臉貼在鍋蓋上。
越往下越燙，石壁從黑變成亮亮的黑，像凍住的糖漿。阿露在上面咳起來，小草小蕨的葉甲邊緣捲起來，發出焦味。
四尊魔像沒事，石頭不怕燙，大黑還伸手摸牆，摸完點點頭，像在說還行。

到底的時候，我的鞋底差點黏住。

黑玻璃。整層樓全是黑玻璃，又滑又亮，映著火光。
空氣乾到舌頭發苦，有硫磺味，有鐵味。十二個圓窪排成一圈，嵌在玻璃地板上，每個窪裡都有一床暗紅的火灰。
南北各一口大釜，黑黑的，冒著熱氣。中間一個心窪，圓圓的，像整層樓的心臟。

「水。」阿露啞著聲音說，「把水省著喝。」

我們帶的水不多。葉膏多，紗布多，水很少。我把水袋收好，數人。八個，一個不少。很好。

第一隻火苗是小蕨發現的。

很小一團，扭來扭去，從窪裡滑出來，落在玻璃上，發出劈啪聲。像小孩，像剛出生的東西，好奇地看我們。
小蕨說好可愛。然後那團火張開嘴，露出牙，撲過來，速度快得看不見。

大白一巴掌，把它拍散了。火星濺開，落在玻璃上，熄了。

「不可愛。」小蕨改口。

更多的火苗從各個窪裡滑出來，三三兩兩，遊來遊去。牠們跑得很快，一下在這間，一下在那間。大白小白專門負責拍，一巴掌一隻，拍得很準。石頭打火，火沒轍。

我站在圈子中間數。火苗出現的地方，移動的方向，停留的長短。橫幾步，直幾步，幾步一個彎。這一層的格子是圓的，轉著走的。但是規律還是一樣：有規律，就能騙。

然後，地面震了。

熱氣從東邊漫過來，牆都晃了。一個很寬很寬的影子，沿著圓圈走過來。不快，但是每一步都很重。走到的地方，火苗自動讓路，像臣子讓路給王。

火元素。

它沒有臉，沒有手腳，就是一大團火，硬是捏成人形。胸口有一個漩渦，慢慢轉，發出風聲。所過之處，玻璃發紅，火苗一隻一隻掉下來，掉進窪裡，活蹦亂跳。

「大黑，上！」我喊。

大黑衝過去，一拳砸在它身上。拳頭穿過去了。火晃了一下，合起來，一點事都沒有。大黑的拳頭燒紅了，牠收回來，吹了吹——魔像居然會吹手，我第一次看到。

「都退開！」我拍一下手，「刀劍沒用！這東西砍不動！」

火元素停下來，漩渦轉向我們。熱浪撲過來，我的眉毛捲了。阿露把我往後拖，小草舉起矛，矛尖燒紅了，彎了。

刀砍不動，矛刺不穿。這不是肉，這是記憶燒成的形。身體打不過的，要用腦打。

我們退到心窪，看著它走。它走得很慢，一個窪，停一停，再下一個窪，順時針，永遠順時針。我數著：停兩拍，走一格。停兩拍，走一格。準得像時鐘。

時鐘。我想起什麼了嗎？沒有，還沒。但是手指自己動了，在空中畫圈，一個，兩個。播棋。是播棋。把子撒出去，一圈一圈撒。

噬紋。我低頭看粉筆。第二層學的噬紋，螺旋往內轉，畫在地上，站在上面會被吸走力氣。就是為這種東西準備的。

「來，聽我說。」我把大家叫過來，「這傢伙順時針走，停兩拍走一格。我們不追，我們跑前面去。心窪是近路，從這裡穿過去，比它快兩格。」

「前面選一個窪，清乾淨，我畫噬紋，然後退一格等它進來。火苗一隻都不能留，留一隻，陷阱就廢一半。」

「為什麼？」小草問。

「噬紋不認人，誰站在上面吸誰。火苗跑進去，白燒兩格。
」我說，「所以先清場，再下套。」

第一次，我們失敗了。

心窪穿過去，東弧第三個窪，清乾淨，大黑小黑守兩頭，我蹲下來描。螺旋，一圈一圈往內，粉筆燙得冒煙。
描完退一格，等。火元素走過來，進窪，光升起來，吸住了，漩渦轉慢了。
我心跳到喉嚨口。

然後一隻火苗從後面滑進來，一頭撞進光裡。光閃了兩下，火苗燒成灰，光暗了一大截。火元素走出窪，漩渦又轉快了，什麼事都沒有，還掉了兩隻新的火苗在我們腳邊。

「我就知道！」我氣得跺腳，鞋底燙得跳起來，「清場！清乾淨再說！」

第二次，我們學乖了。大白小白把前後三間全掃一遍，連灰都不剩。
小草小蕨站在路口，來一隻拍一隻。阿露蹲在我旁邊，葉膏隨時備著，燙傷馬上敷。
大黑小黑一左一右，替我擋熱浪。我描，描完退，等。

火元素進來了。光升起來，吸住，漩渦慢下來，慢下來，火矮了一截。五格吸滿，光滅了。它走出去，矮了一半，掉火苗都掉不利索了。

「有效！」小蕨跳起來，「再來一次！」

「西弧！跑！」我喊。

穿心窪，跑西弧，清場，描，退，等。第二次的光升起來的時候，火元素的漩渦幾乎停了。
它站在窪中間，不動了。火一層一層暗下去，從白變黃，從黃變紅，從紅變黑。
掉下來的火苗也不跑了，圍在旁邊，靜靜地燒。

然後，它放開了。

不是倒下，是放開。胸口的漩渦鬆開，一圈一圈散掉，像憋了很久的一口氣，終於吐出來。
火散開，飄起來，變成滿屋子的光點，涼涼的，不燙手。板子一下子涼了。
風吹過來，第一次是涼的。

火苗們安靜下來，擠在一起，燒得很小，很乖。

我坐在玻璃上，動都不想動。八個全坐下來，圍成一圈，沒人說話。阿露給每個人分水，一人一小口。大黑把燒紅的拳頭泡進水袋，水滋的一聲，冒煙了。大家都笑了。

餘燼卷軸就在大釜後面，包在黑布裡。打開，字浮起來，燙進腦子：生紋的畫法。圓圓的，琥珀色的，畫在空地上，會有東西應聲而來，強弱看畫的人有多強。

第三個紋印。手在空中描了兩下。記住了。魅紋，噬紋，生紋。手背發燙，燙完，線就沉進去了。

然後記憶來了。

地上很多小坑，一排一排。手裡一把種子，圓圓的，滑滑的。
一個聲音說：數清楚，再撒。一坑幾顆，心裡有數，手就不會亂。
撒完一圈，看看哪裡多，哪裡少。多的拿走，少的補上。
這就是播棋。

播棋。我也玩過。
教的人手黑黑的，指甲縫有墨水，數種子的時候很快：數清楚再撒。跟圍棋的手不一樣，跟西洋棋的手也不一樣。
三雙手，三個人。不是同一個人。
是很多人。都是真的，都是我下過的棋。

「是誰。」我抱著頭，「你們到底是誰。」

想不起來。一想就頭痛，像撞到牆。但是這次，牆後面好像有光。有個很小的洞，光漏進來一點點。

「喂。」操作員的聲音，聽起來有點不一樣，沒那麼嗆，「還活著？這層熱成這樣，我以為你們熟了。」

「……活著。八個都在。」

「看到了。火放開了，不是打死的。
」他停了一下，翻紙的聲音很慢，「數據上，它本來就是被關住的。你們把它放了。幹得不錯——這句不許跟別人說。」

滋——。斷了。這次他沒補刀。我看著空氣，笑了。

梯子在南大釜後面，往下，吹上來的不再是熱氣，是潮氣，還有一種很特別的味道：麵餅，湯，機油，還有人聲。很遠，但是是人的聲音。好久沒聽到這麼多人的聲音了。

我在心裡數。這一層，我一個都沒殺。火是放走的，苗是拍昏的，隊伍還是八個，多了三個紋印。

大黑先下，小黑跟著，大白小白，小草小蕨，阿露走中間，我斷後。黑玻璃在身後涼下去，光點還飄著，像送我們。

——第三局，終了。贏的是放手。
