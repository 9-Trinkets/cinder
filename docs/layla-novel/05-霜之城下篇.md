# 第五章：霜之城（下）

下半夜，我守。艾絲翠德沒睡，坐在北口，擦劍，一下一下。雪落在劍上，化了，又落。

「睡不著？」我走過去，坐下。

「籠子裡睡多了。」她說，「出來反而不習慣，地方太大。」她擦著劍，很久，忽然說，「抓人的命令，我下過一次。就一次。下完，全隊譁變，我第一個被綁。值了。」

她沒看我，我沒問。就這樣坐著，雪落下來，世界很靜，靜得能聽到三間王座那邊，鎖鏈響了一下，又一下。像在數日子。

天沒亮，第三波來了。沒有號角，沒有喊聲，三扇門，自己開的。

先出來的是兵，灰壓壓的，三個方向一起漫出來。然後是三個當家的，走在各自隊伍前面：范恩領主，狼皮大衣，刀快得看不見；托林戰帥，大錘，比人還長；希爾文夫人，瘦，靜，眼睛像冰，走在最後，慢慢走。

滋——滋滋——操作員上線，又平又老，一點都不急，急得讓人害怕：

「夠了。上面在查我的區，因為你的錯。」停了很久，「全部，壓上去。碾碎中庭。我沒時間了，你也沒有。」

「三路全守！」我喊，聲音劈了，「艾絲翠德北！賈米爾東南！四尊跟我去西南！艾納阿露守中間！小草小蕨小灰，跑起來，哪裡喊去哪裡！小火，守台子！」

北邊打成一團。范恩領主太快了，快到艾絲翠德的盾跟不上，一刀，兩刀，盾上全是口子。我描傳紋，人一閃，到他側面，耳朵嗡，血流，矛逼他轉身。艾絲翠德抓住一秒的空，整個人撞上去。盾碎了，人沒倒，劍從碎盾後面捅出去。范恩倒了，看著碎掉的盾，笑了，閉眼，不動了。艾絲翠德坐在雪裡，抱著碎盾，半天沒起來。盾跟了她很多年，比籠子還久。

東南打成打鐵鋪。托林的大錘對賈米爾的拳頭，噹，噹，雪震得跳起來。鐵甲太硬了，矛捅不進，我換法子，蹲下去描噬紋，螺旋，一圈圈，描在托林腳下。光升起來，吸住，錘慢了，人矮了。賈米爾抱住錘柄，大黑小黑按錘頭，錘脫手，插進雪裡。托林跪了，躺下去，看著天，笑了，不起來了。賈米爾胳膊上的裂更大了，管子冒氣，石頭渣子往下掉。艾納跑過來看了一眼，搖頭，石頭，他補不了，只能看著。這一眼，比什麼都重。

西南，我帶四尊到，小灰探路。霜豹的人不正面打，弩箭從霧裡來，毒針從雪裡來。小灰聞得出埋伏，低聲叫，我們繞開，噬紋封路，進來的一隻一隻被吸乾。霧後面，希爾文夫人看著，看了很久，開口，聲音很輕：

「你就是那個放走火的人？」

「是我。」

「火都放了，人呢？」她問，「我們呢？放不放？」

我愣住了。燈在懷裡，暖的。小灰站在我旁邊，是圍來的，自己留下來的。小火在中庭燒著，是生出來的，認家的。八個，十個，十一個，全是自己走過來的，沒一個是綁的。

「綁你們的，是誰。」我問，「王座，還是你們自己？」

「王座沒了。」她說，「你們打沒的。現在，沒人綁我們。我們自己站著，自己也不知道為什麼站著。」

「那就別站了。」我舉起燈，光照過去，照在她臉上，照在她身後的兵臉上。她眯起眼，沒有躲。看了很久，眼淚掉下來，變成冰渣，掉在雪裡，砸出小坑。她走過來，走到光裡，站住。身後的兵，一個一個，放下弩，走進光裡，站住。霧散了。

「……我投降。」她說，「不是輸，是醒了。燈借我，再照一下。」

三路，全暗了。號聲停了，喊聲停了，只剩風聲。我站在中庭中間，數人，數了三遍，腿軟了，坐下去，起不來。阿露跑過來，渾身是血，分不清是誰的，抱著我哭。小蕨也哭，邊哭邊數，數完喊：「都在！都在！一個不少！」

五群人圍上來。鹽灘的妮薇抱著毯子，分給傷員。玻璃鎮的艾莉絲卡舉著燈，幫忙照亮。羊毛鎮的阿馬魯把最小的孩子扛在肩上，孩子笑了，第一個笑。綠息鎮的艾貝妮塞給阿露一把種子，說回去種，種在暖的地方。黃銅鎮的陳鈺昕把五枚代幣捧過來，放在我手心，很用力地按了一下：「修東西的人，謝修東西的人。」

「深井村呢？」我問，「第六個鎮，沒人嗎？」

沒人說話。賈米爾轉過身，看著雪山，很久。我走過去，站在他旁邊，沒說話。欠森林的那個答案，又多了一筆。來去的路通了，回去的時候，一筆一筆還。

南邊的大鐵門，開了。後面是暖氣，香的味道，燭火的味道。艾納站在門口，看著那條路，站了很久，手不抖了。「老家。」他說，「聖堂。進去，都聽我的，別亂走，別亂問。」

滋——滋滋——操作員，最後一次，聲音很遠，像從很深的地方傳來：

「三路全暗。區沒了。上面記著：超出預期。」停了很久，「核心見。」

斷了。控制台，暗了。這層的位子沒了。他退回去了，退到不知道哪裡，等我。是王座，還是別的，我不知道。我只知道，路還在腳下，一層一層，往下走，總會走到他面前。到時候再問，他到底是誰。

我收起代幣，分好裝備，數人。九個，加艾絲翠德，加艾納，十一個。阿露把最後一塊葉膏分完，抬頭看我，眼睛亮亮的。陳鈺昕追上來，又塞了一包齒輪和釘子，說路上修東西用得上。

「走。」我說，「下一層，聖堂。艾納帶路。」

雪在身後小下去，香氣漫上來。第五局，終了。贏的是守住。
