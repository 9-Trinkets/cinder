# 第五章：霜之城（下）

天沒亮，第三波來了。沒有號角，沒有喊聲，三扇門，自己開的。

我深呼吸，開怪了。大家聽到，笑了，緊張散了一半。小蕨還學我深呼吸，吸太大口嗆到，咳個不停，笑得更兇了。

先出來的是兵，灰壓壓的，三個方向一起漫出來。北邊狼嚎，一聲接一聲，壯膽。東南鐵靴跺地，一下一下，整齊得嚇人。西南沒聲音，一點聲音都沒有，最嚇人。

然後是三個當家的，走在各自隊伍前面：范恩領主，狼皮大衣，刀快得看不見。托林戰帥，大錘，比人還長。希爾文夫人，瘦，靜，眼睛像冰。走在最後，慢慢走，眼睛盯著我，或者說，盯著我懷裡的燈。

「艾絲翠德，你守北邊。賈米爾，你守東南。四尊跟我去西南。」

「好。」七八個聲音。艾絲翠德加了一句：「活著回來。」

北邊打成一團。范恩領主太快了，艾絲翠德的盾跟不上，一刀，兩刀，盾上全是口子。狼群嚎起來，一聲接一聲，給他們的王壯膽。

我傳過去，到他側面。鼻血流，矛逼他轉身，他轉，我再傳，另一邊，又逼他轉。轉第三次，他煩了，刀慢了一拍，嘴裡說了句什麼，好像是，又是你。

艾絲翠德的左肩早就中了一刀，一直忍著沒說，這時候不管了，整個人撞上去。盾碎了，人沒倒，劍從碎盾後面捅出去。

范恩倒了，看著碎掉的盾，笑了，閉眼，不動了。北邊狼群嚎了一聲，很長，散了，頭也不回。

艾絲翠德坐在雪裡，抱著碎盾，半天沒起來。盾跟了她很多年，比籠子還久。她把范恩的刀收起來，說以後還他家，刀是好刀，不該爛在雪裡。

東南打成打鐵鋪。托林的大錘對賈米爾的拳頭，噹，噹，雪震得跳起來。鐵甲太硬，矛捅了三處，胸，肩，腿側，全滑開，連白印都沒留下。

我退開兩步，不打了，看。下棋的，看棋形，看三遍，看到會背為止。

第一遍，看他抬錘，肩動，腰動，腳動，動作全連在一起，水一樣，沒縫。

第二遍，看落點，每一錘都砸同一個地方，賈米爾站的地方。他不是亂砸，他算好了，逼石頭硬接，石頭總會裂。這人會下棋，用錘下的。

第三遍，看發力。肩，腰，腳，膝。肩，腰，腳，膝。前面三個順，第四個頓一下，很小的一下，左膝，每次發力前頓一下。舊傷，甲片底下是空的。

還不確定，試一次。假裝往左去，眼睛看右膝。他果然先護左邊，慢了半拍。是那裡，沒跑了。

就是那裡。

我滑進去，矛尖送進膝蓋彎，他跪了，錘杵在雪裡，撐住，沒倒。我蹲下去描噬紋，螺旋，一圈圈，描在他腳下。光升起來，吸住，錘舉不起來了，人一點一點矮下去。

賈米爾抱住錘柄，大黑小黑按錘頭，錘脫手，插進雪裡。托林躺下去，看著天，笑了，不起來了。

賈米爾看著那把大錘，說，好錘。托林笑得更開了，說送你了，不要。賈米爾搖頭，說太重，拿不動，留著吧。

鐵公羊的人圍過來，把他抬走。抬得很穩，一步一步，沒人回頭看我們。

賈米爾胳膊上的裂更大了，管子冒氣，石頭渣子往下掉。艾納跑過來看了一眼，搖頭，石頭，他補不了，只能看著。這一眼，比什麼都重。

西南，我帶四尊到，小灰探路。聞得出埋伏，低聲叫，我們繞開，噬紋封路，進來的一隻一隻被吸乾。中庭那邊，小火燒著，火變小了一圈，累得蹲下去，漏過去的全被燙了腳，退回來。

霧後面，希爾文夫人看著，看了很久，開口，聲音很輕：「你就是那個放走火的人？」

「是我。」

「火都放了，人呢？」她問，「我們呢？放不放？」

「你本來打算活捉我吧。」我說，「看半天了，從霧裡。」

她頓了一下，笑了，又累又真：「對。本來是。看到燈，改主意了。」

「這盞燈我不能借出去。」我把燈舉高，「不過光可以讓大家看清楚。你過來看看就好。」

她走過來，走到光裡，站住，眯起眼，沒有躲。看了很久，問：「這燈，哪來的？」

「朋友的，弟弟的。」我說，「蒸汽村，一個十一歲的小孩，小宰德。他說爸爸媽媽留下的，燈總能照穿石頭。」

她整個人晃了一下。按住額頭，霧一樣的人，臉上第一次出現裂痕：「小宰……德。這個名字……」她念了兩遍，搖頭，想不起來，越想頭越痛，蹲了下去。

身後的兵騷動起來，放下弩，圍過來，又不敢碰她。我走過去，把燈放低一點，光照在她臉上，暖暖的。她哭了，眼淚掉下來，變成冰渣，砸出小坑。

「……我投降。」她說，「不是輸，是醒了。燈借我，再照一下。」

我把燈遞過去，她雙手捧著，像捧小孩，很輕，很小心。

身後的兵，一個一個，放下弩，走進光裡，站住。霧散了。

三路，全暗了。只剩風聲。豹的弩堆成一堆，狼的刀插在雪裡，鐵甲的錘橫著放。

艾納沒回中間，留在原地，給倒地的狼兵和鐵甲包紮。敵我的血混在一起，分不清。艾絲翠德看了一眼，沒攔，轉身去收自己的劍。

我站在原地，看著，看了很久。放和綁，差很多。今天，我好像又懂了一點。

我站在中庭中間，數人，數了三遍。腿軟了，坐下去，起不來。阿露跑過來，渾身是血，分不清是誰的，抱著我哭。小蕨也哭，邊哭邊數，數完喊：「都在！都在！一個不少！」

五群人圍上來。鹽灘的妮薇抱著毯子，分給傷員。玻璃鎮的艾莉絲卡舉著燈，幫忙照亮。

羊毛鎮的阿馬魯把最小的孩子扛在肩上，孩子笑了，第一個笑。綠息鎮的艾貝妮塞給阿露一把種子，說回去種，種在暖的地方。

黃銅鎮的陳鈺昕把五枚代幣捧過來，放在我手心，很用力地按了一下：「修東西的人，謝修東西的人。」

她頓了一下，拉著艾莉絲卡姐蹲下去。兩顆頭湊在一起，扳手，燈，拆，擦，接，裝。一下，兩下，燈亮了。暖黃色的，小小的一盞。

全場安靜了一秒，然後不知道誰先開始鼓掌。掌聲混著風聲，傳得很遠。艾莉絲卡姐抱著燈，哭了，笑著哭的。

妮薇姨走過來，翻開小本子，給我看，口糧還剩幾天，傷藥還剩幾包，清清楚楚。我說記得真好，她說管後勤的，記性就是命。

「深井村呢？」我問，「第六個鎮，沒人嗎？」

沒人說話。賈米爾轉過身，看著雪山，很久。我走過去，站在他旁邊，沒說話。妖精王后霧邊的身影，還有她沒說完的話。如果回去，把看到的說給她聽。來去的路，通了。

南邊的大鐵門，開了。希爾文夫人捧著燈，站在霧邊，看我們走，像送行。她沒說話，燈替她說了。

後面是暖氣，香的味道，燭火的味道。艾納站在門口，看著那條路，站了很久，手又開始抖了。

香飄過來，他往後退了一步，捂住鼻子，彎下腰，乾嘔。阿露衝過去拍他的背，他擺手，站直，臉白得嚇人。

「這個香。」他慢慢說，「聖堂的香，聞了會老實，會把什麼都說出來。我以前配藥，就是配解這個的。被發現了，袍子當場扒掉，當著所有人的面。布撕開的聲音，我到現在還記得。」

他看著門裡面，燭火一排一排，看不到頭，輕聲說：「老家。進去，都聽我的，別亂走，別亂問。認出我的人，讓我來應付。」

阿露走過去，拉住他的袖子，說老師，我陪你。他愣了一下，笑了，第一次笑，眼睛彎彎的，很快又收回去，深呼吸，往門裡走。袍子下擺掃過雪，留下兩道痕。

滋——滋滋——無線電，整場第一次響，聲音很遠，像從很深的地方傳來：「三路全暗。區沒了。上面記著：超出預期。」停了很久，「核心見。」

斷了。我捏著無線電，愣住了。整場不說話，打完說三句。核心是哪裡，我不知道。我只知道，路還在腳下，一層一層，往下走，總會走到他面前。到時候再問，他到底是誰。

我收起代幣，分好裝備，數人。九個，加艾絲翠德，加艾納，十一個。我把筆還給妮薇姨，說帳先放你那，回去再對。她把筆收好，說去吧，早去早回。

阿露把最後一塊葉膏分完，抬頭看我，眼睛亮亮的。陳鈺昕追上來，又塞了一包齒輪和釘子，說路上修東西用得上。

「走吧，下一層是聖堂。艾納，你帶路。」

雪在身後小下去，香氣漫上來。第五局，終了。贏的是守住。
