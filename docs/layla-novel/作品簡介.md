# 《蕾拉》（Layla）作品簡介

```
【宣傳標語】
執黑者先行。既然死局無解，那就掀翻棋盤。
——在這座以人命為子、步步皆殺的深淵裡，她是待宰的棄子，還是破局的棋手？
```

---

### 【內容簡介】

**在深不見底的玄武岩石室中甦醒時，少女失去了所有的記憶。**

沒有名字，沒有過去。  
她手中唯有一支散發微溫銀芒的白堊粉筆，以及一身平滑如第二層皮膚、與陰冷古窟格格不入的炭黑無縫緊身衣。  
當她茫然站起身，耳畔傳來的是神祕導引者乾硬而疲憊的低語：  
*「底下的路很長。學會規則，不要死。」*

然而，這座名為「深淵」的地下死地，並非尋常的怪物迷宮，而是一場殘酷精密的活體對弈——
- **第一層的十九路玄武岩網格**，是兩尊石魔像以命搏殺的圍棋氣口；
- **第二層的迷霧古林**，是十六妖精軍陣交錯推進的西洋棋殺局；
- **第三層的高溫火坑**，是十二圓窪間以時序循環流轉的播棋死局……

伴隨著她在石板上劃下的道道神秘幾何印記——  
**翻轉敵友心智的魅紋、吸乾能量生機的噬紋、折疊斷點跳躍空間的傳紋、自虛無中召喚僕從的生紋，以及將魂魄強行鎖定軀殼的縛紋**，少女以令人戰慄的幾何直覺連破死局，一步步往更深處探索。

但隨著層級下降，地底展現的並非奇幻寶藏，而是一座森冷壓抑的階級牢籠：  
硫磺瀰漫的開採殖民地、身著粗糙灰襖被視為耗材的底層工民，以及高居深淵核心之上、以冷酷算度支配整座地城的幕後主宰。

她是誰？為何能看穿這座深淵底層最嚴苛的運行規則？  
耳邊低語的導引者究竟在旁觀什麼？  
當每一步計算都指向不可逆的犧牲與死局，這名手執粉筆的黑衣少女，將用自己的意志給出答案——

**「黑子先行。如果你們定下的規則只有毀滅，那我便掀翻這整座棋盤。」**

---

### 【核心看點】

1. **古典棋局博弈 × 底層幾何法則**  
   摒棄數值膨脹與無腦開掛。圍棋氣口生殺、西洋棋位格牽制、播棋循環流轉。每一場戰鬥皆是極限空間計算與幾何推演的智力死鬥。

2. **嚴酷森冷的反烏托邦社會構建**  
   地下城不僅是戰場，更是一個階級嚴苛的人性熔爐。從被當作棄子的奴工礦坑，到以精密偽善統治的白瓷假面階層，深入剖析權力壓迫與生存尊嚴。

3. **冷靜堅毅、拒絕妥協的破局者**  
   知性、沉穩、洞察敏銳的孤高少女蕾拉。在殘酷的規則與無盡的算計面前，她不依賴奇蹟與救贖，以粉筆為刃、幾何為盾，硬生生在絕境中踏出一條反抗之路。

### 【創作者聲明：人機共構的文學探索】

> **「這是一部由人類構思引導、與人工智慧協同創作的長篇小說。」**

在本書的創作過程中，人類作者與先進 AI 展開了一場深度的協作實驗：
- **人類作者（Human Architect）**：主導宏觀世界觀架構、核心哲學命題、幾何博弈規則、情節走向與人性抉擇的導演把控；
- **人工智慧（AI Co-creator）**：協同進行場景細節描寫、空間博弈幾何邏輯校驗、冷冽感官氛圍渲染與跨章節語調的嚴密一致性。

正如《蕾拉》故事中所探討的命題——在嚴苛的規則、代碼般的幾何指令與命運框架下，什麼才是真正的心智、自由意志與人性光芒？  
這部小說的誕生本身，正是人類想像力與機器理性交會對話的見證。
