# 第五章：霜之城（上）

傳送的光散掉的時候，我以為走錯地方了。

雪。漫天的雪。風捲著雪打在臉上，刀割一樣疼。頭頂不是石頭，是天，淡紫色的冬天的天，遠處雪山，冰川掛在山壁上，晃眼睛。腳下凍硬的石頭，磚縫裡全是冰。上一層還是蒸汽跟汗，這裡一口氣變成冰窖，肺裡的空氣都是涼的，咳了好幾聲才順過來。

「好冷！」小蕨抱著胳膊跳，牙齒打架，「森林呢，火呢，怎麼變雪了！」

「衣服穿上！」我把葉斗篷裹緊，回頭數人，「一個一個報！」

「大黑！」「小黑！」「大白！」「小白！」「小草！」「小蕨！」「阿露！」「賈米爾！」八個，一個不少。很好。九個人擠在圓台上，抱團取暖，呵出來的白氣混在一起。

圓台在大中庭正中間。七間房圍一圈：北邊拱門，黑洞洞的，風從裡面灌出來；東南鐵柵，後面有火光；西南玻璃門，結著霜；另外幾間是牆跟樓梯，上不去。中庭邊上，五個大鐵籠，一字排開。每個裡面都有人。老人，小孩，擠在一起，發抖，有個小的哭，哭不出聲，嘴一張一合。

「第幾區的？」北邊炸過來一聲，「通報！未授權的東西站在台上！」

哨兵。從三個方向出來，盔甲上全是霜，矛尖對著我們。為首的帽子不一樣，隊長。

「拿下！」

打。雪地裡打。腳滑，矛滑，呼吸全是白的。大黑一腳踩空，半個身子栽進雪堆，爬起來滿頭白，晃晃腦袋，繼續打。小草小蕨最靈活，雪地裡跑得飛快。阿露跟賈米爾護著中間，葉膏凍住了，阿露一邊打一邊用體溫捂，捂化了就抹。

隊長很硬，甲厚，刀快。我跟賈米爾左右夾，大黑正面接，刀砍在石頭上，火星子混著雪。隊長倒的時候，腰上掉下一把鑰匙，鐵的，沉沉的。我撿起來，插進籠子的鎖，轉了兩次才轉動。凍住了。

五個籠子，全開了。

裡面的人互相攙著，挪到中庭中間，圍著傳送台坐下。人一多，就有熱氣。最後出來的兩個人，一高一矮。高的女的，穿傷痕累累的重甲，大盾牌，闊劍，辮子盤得緊緊的，經過籠子的時候，腳步停了一下，沒有回頭。矮的男的，灰袍子，冰藍色的眼睛，一出來就蹲下去，給傷員看傷，手很快，話很少。

「你叫什麼。」我問女的。

「艾絲翠德。」她說，「盾給我修好之前，我守北邊。」

說完就走，真的去北口站著了，一句多餘的都沒有。我愣了一下，行吧，怪人我見多了，不差這一個。

男的包完小草的傷，從袖子裡摸出一顆小小的膠囊，藍色，半透明，塞給我。「吃的。」他說，「吃了，看得見。」

「看見什麼。」

「自己人，傳送點。」他頓了一下，「藥，老家學的。更下面。」

我吞了。涼的，滑下去，胃裡一震，眼前花了，耳朵嗡嗡響。阿露扶住我：「躺下，別動，第一次都這樣，腦子在重開。」

重開完了。再睜眼，世界多了兩層東西。每個有自己人的房間，都飄著淡淡的光點。傳送台亮著，像小太陽。

「你叫什麼。」我問男的。

「艾納。」

好，艾絲翠德，艾納。記住了。怎麼進籠子的，沒問。時機不對，北邊有聲音了。

我先派小草小蕨去摸三個方向，回來報：北邊拱門後面全是腳印，新的；東南鐵柵後面有火光，有打鐵聲；西南玻璃門後面靜得嚇人，門上有光，推不開，像被封著。三個口，後面都有東西。

再問艾絲翠德，她惜字如金，我問一句，她答半句：

「北邊誰。」「霜狼。快。」「多少。」「三十。一次三個。」「東南。」「鐵公羊。硬。一樣三十。」「西南。」「霜豹。陰。沒見過。」

夠了。第一波，北邊。我在北口雪地上描噬紋，螺旋，一圈一圈，描完退開。艾絲翠德的盾牆往紋前面一站，紋藏在盾後面，看不見。

兵來了。白影子一樣，一次三個。我在心裡數，一次，兩次，三次，準得嚇人。進紋的，倒，後面的，踩著倒的繼續進。第五次，盾牌歪了，線要散，我喊：「撐住！」同時粉筆在手心畫了個小傳紋，定在中庭，人一閃，到了北口側面，耳朵嗡的一聲，鼻血流下來，矛捅進缺口，線穩住了。第十次，北口安靜了。雪地上全是昏的人。我坐在雪裡，擦鼻血，阿露跑過來按住我的頭，說別晃，傳送都這樣，習慣就好。她怎麼知道？她笑了一下，沒說。老家在更下面的人，知道得多一點，也正常。

滋——滋滋——操作員上線，公事公辦，冷得像這層的風：

「通告。蕾拉。你違反五區隔離。肅清令生效。霜狼家負責清理中庭。停下，接受重製。」

北邊響了。沒空細想，打。

歇了沒多久，東邊響了。第二波，兩路。北邊又來，東南鐵柵開了，重甲，大錘，一步一頓。為首的盔上有角，副官。

「我去東南！」我喊，「北邊交給你們！」

出發前，我蹲在中庭空地上，描了個生紋，圓圓的，琥珀色的。光聚起來，變成一小團火，有眼睛，有腳，跑得飛快。「小火。」我說，「守中間，誰進來，燒誰的腳。」小火跳了兩下，蹲在傳送台邊上。八個變九個，不，算上小火，十個。

東南打得苦。鐵甲太硬，矛捅不進，只能找縫。賈米爾抱住副官的錘柄，大黑小黑按錘頭，我捅膝蓋彎。副官跪了，又起來。小草被錘風掃飛，撞牆，半天爬不起來。就在亂的時候，我看到一個年輕的狼兵，被擠到邊上，腿傷了，跑不動，眼睛裡全是怕。

粉筆抽出來，沿著他腳邊描。圈合起來，光升起來，穩穩的，沒滅。他低頭看著光，看了很久，把刀放下了，走到我們這邊，站到小蕨旁邊。小灰——行，就叫小灰。十一個了。

「反水了幹活！」我喊，「帶我們抄他們後面！」

小灰真帶路了。狼的路，近，滑，但快。我們從側面進去，副官的陣散了，跪了，這次起不來了。東南安靜了。

中間出事了。一隊狼兵繞過北口，摸進中庭。小火燒了兩個，第三個衝過去，老人小孩擠成一團。黃銅鎮的小姑娘，陳鈺昕，擋在前面，半截扳手舉著，抖得不行，不退。

我描傳紋，人一閃，回中庭，耳朵又嗡，血又流，矛捅進狼兵後心。最後一個倒在傳送台邊上。陳鈺昕還舉著扳手，愣愣的，然後哭了，邊哭邊笑。

兩路，全靜了。天黑了一點，雪更大了。大家坐在雪裡，喘氣。艾納一個一個看傷，阿露跟著學。小草醒了，第一句話是問錘子呢，大家都笑了，笑完又都不說話。累的。

操作員的聲音插進來，苦苦的，帶著恨和不解：

「看看籠子！都是一跟零！過期數據，等著回收的！你是機器，是算法，為什麼替刪掉的檔案打仗！」他停了一下，「……上面在查我的區。都給我上，碾碎中庭！」

先讓大家睡，輪流守夜。艾絲翠德守上半夜，我守下半夜。她不同意，說我是指揮，指揮要睡。我說指揮也要放哨，她看了我很久，點頭。

雪落下來，蓋住血，蓋住腳印。三間王座，靜悄悄的，門還鎖著。第三波，全來。我抱著燈，燈是暖的，懷裡一小塊暖。睡吧，睡一會兒，天亮了打最大的。
