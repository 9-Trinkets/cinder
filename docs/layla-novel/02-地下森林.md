# 第二章：地下森林

梯子很長，越往下越涼。

涼到一半，風變了味道。上面是煙跟血，這裡是水跟葉子，甜甜的，像果子泡爛在水裡。我踩到底，抬頭，愣住。

頭頂開了個大洞，光從裂縫漏下來，一道一道，插進霧裡，乳白色的。洞頂鋪著發光的苔，綠的藍的，還有一點紫，一明一滅，跟呼吸一樣。根從上面垂下來，比柱子還粗。蕨長得比我高，葉子寬得能遮雨。地上全是爛葉子，踩下去出水。

森林。地底長了一座森林。

「都下來了？」我小聲問，「報數。」

石頭們一個一個應。大黑，小黑，大白，小白。八隻眼睛，亮了四雙。加上我，九個，齊了。

「霧大，跟緊，別出聲。」

走沒多久，霧裡傳來一聲，嗒。脆的，石頭敲石頭。隔一會兒，又一聲。巡邏，有規律。

我撥開蕨葉，眯著眼看。

霧裡站著一個很高的影子。走近了才看清，瘦，長，皮膚白得像樺樹皮。耳朵尖，從頭髮裡支出來。眼睛又大又綠，天暗的地方會反光。穿硬葉甲，拿葉矛，矛拿得很穩，穩得不像活的。

牠走幾步，停，聽，再走。是練過的。跟哥布林那種撲的不一樣，這是軍隊的走法。

我縮回來，背上全是汗。一個打一個，我行。一個打一支，我死。這裡霧這麼大，矛有幾支，我數不出來。

那就別硬打。動腦，動大家。

我把四尊攏過來，聲音壓到最低：「大黑小黑站前面，只擋不追，矛來了用手臂接，接完推開。大白小白站兩邊，誰繞過來就往誰前面站，擋路就好，不用打。」

四顆頭一起點。灰掉下來。

「我去前面看。拍兩下就往前三步，拍一下就停。記住了？」

記住了。石頭記性比人好。

我一個人摸過去，貼著根，踩著爛葉子。巡邏隊過去一隊，我在心裡記。快的隊，沒多久就回來。慢的隊，很久才回來。這裡直走幾步，那裡轉彎幾步，格子是活的，會走路，我就記活的。

看到落單的了。一隻妖精兵，離隊伍有點遠，蹲在水池邊喝水，矛靠在石頭上，夠不著。

我學鳥叫，兩聲，巨難聽，但是夠大。

妖精兵抬頭。大黑小黑從霧裡走出來，一步，兩步，三步，站定。妖精兵抓矛就刺，大黑不閃，用手臂接，火星子一串，矛尖斷了。大白跨一步，把牠回去的路堵了。

妖精兵左右看，慌了。斷矛一丟，轉身就跑，邊跑邊吹哨，又尖又短。

「回來！」我拍一下。

四尊定住，不追。哨聲把一整隊引過來，三隻，排一排，矛放平。我們早退回霧裡了，地上只剩半截斷矛。牠們轉了一圈，沒找著，吹兩聲短哨，整隊走了，腳步聲遠了，一個調子。

我躲在根後面，差點笑出來。快有什麼用，照規矩走的，全是明牌。規矩摸清了，隨便騙。

下一個，試粉筆。

等巡邏隊散了，我挑了只走最後的。粉筆抽出來，沿著牠腳邊描，轉彎，再轉彎，手穩，心定。最後一筆合上，光升起來，跟圍魔像時一模一樣，我心都提起來了。

妖精兵低頭，看了一眼。光閃兩下，跟被風吹一樣，滅了。圈裡的紋褪了，掉灰。牠抬腳跨出來，看我一眼，眼睛裡沒有火，只有累，特別深的累。搖搖頭，走了，步子都沒亂。

我蹲在滅掉的圈旁邊，想了半天。圍魔像，一合就亮，又穩又暖。這個，亮不起來。是我太弱了。小的都圍不住，這層的傢伙，級別比我高，心比我硬，環接不住。

行，先不圍。先打，先算，先升級。等變強了，再回來。

我們就這麼打了一整路。敲石頭，引一小隊出來，兩尊堵前面，兩尊封側面，我繞後面，矛尾敲最後一個。絕不貪，絕不追。傷的退下來，沒傷的頂上去。我記，誰幾步一回，誰跟誰一夥。霧幫我們，根幫我們，白堊舊路最好走，沿著走，不迷路。

葉膏就是這麼來的。敲昏第三個，從牠腰上摸下一包綠膏。抹傷口上，涼涼的，血一下就止住了。大黑胳膊裂了，我也給牠糊一層。牠低頭看著，眼睛眨了一下。石頭敷藥有沒有用不知道，反正牠沒拒絕。

打著打著，身體變了。說不上來，粉筆更燙，手更穩，跑起來氣更長。像弦又上緊一格。我知道，這叫升級，雖然沒人告訴我。

滋滋聲插進來，操作員公事公辦：「數據動了。等級二了。繼續。」

等級。原來有這東西。上面那層沒感覺，人人都一樣。這層倒好，身分越高越強，連我也要一級一級爬。行，公平，我喜歡公平的。

林子越走越開，霧薄了，光亮了。前面一片空地，白堊線彎彎曲曲。八個妖精兵，站一排，動作齊得嚇人，呼吸都一個調。棋盤上的卒子本子，活的。

卒子。這詞一出來我就懂了。上層是圍，這層是棋。圍棋子人人平等，這裡可不，個個有身分：兵往前頂，騎士走邊，主教發號令，重裝當牆，王后跟王壓最後。身分不同，打法不同。要贏，照身分吃，先小的，後大的。硬衝這條線，五個會被串成糖葫蘆。

我繞著空地走一圈，看地。東邊水池，滑。西邊根最多，路最窄。隊形齊，可是換防的時候，兩頭總慢一拍。那一拍，就是洞。

「聽我說。」我把四尊叫過來。

「等下我丟石頭，東邊響，他們往東看。大黑小黑從西邊進，只打最邊上兩個，打完就跑。」

「大白小白跟我，我們去另一邊。別貪心，一次兩個就好。」

石頭丟出去，啪。東邊轉頭。大黑小黑進去，兩巴掌，倒兩個，退。我帶大白小白進另一邊，矛尾敲昏一個，推倒一個，退。剩下四個，亂了，互相喊，互相看。八個變四個，能打了。四尊排開往前壓，我後面補，專挑拿矛的手。一個一個倒，全是昏的。我下手全是關節脖子，身體自己知道，敲哪昏不死。

剩最後兩個，被逼到水池邊，背靠背，矛舉著，不跑了。小的抖，大的把小的往身後擋了擋。

我看著他們，粉筆在手裡發燙。打穿這一排，弦又緊一格，手穩得很。現在，應該成了。我蹲下來，沿水池濕地描。圈合上，光升起來，又穩又暖，跟圍魔像那次一樣。兩個兵低頭看光，光映在臉上，一閃，一閃，沒滅。

成了。

光暗下去，兩個兵放下矛，走過來，站我後面。小的還抖，大的拍拍他。我給他們取名，大的小草，小的叫小蕨。路邊的名字，好養活。

「跟著石頭走。」我說，「別跑散。」

七個了。隊伍七個了。

就是這時候，我看到她了。

妖精王后。

她站在林子那頭，比所有妖精都高。頭髮編著，戴一圈葉戒，靜靜發光。她走個不停，東邊看看，西邊看看。路線滿得嚇人，一格不空。

我數著，越數心越沉。兵守線，騎士跑邊，主教縮角，只有她，滿場跑。跟下棋的人把后走遍全盤似的，一格不放過。走著走著，她停下來，按著額頭，像頭疼。像在找什麼，又想不起來找什麼。

然後她看到我們了。四尊魔像，兩個妖精兵站我後面，我坐地上喘。她走過來，很慢，眼睛黏在小的那兩個身上，越走越快，到霧邊又停了，搖頭。不是。不是他們。她也不知道不是什麼，反正不是。

「……你們，跟著她？」她問小草小蕨，特別輕，「記得我嗎？」

兩個兵搖頭。一齊搖。什麼都不記得。

她沒再問。轉身走了，接著找。走幾步，回頭看我。那眼裡沒殺氣，只有急。掉了特別重要的東西，怎麼找都找不著的那種急。

我胸口悶得慌。她在找誰？這兒只有樹，只有霧，只有我們。她找的那個，是不是早就不在了？

王座在林子最深處。大活樹，根盤成椅子。

妖精王坐上面，穿深色葉斗篷。兩邊站主教，拿彎木杖。

外面重裝哨兵，跟兩堵牆似的。騎士在霧裡走，又快又輕。

王看看我們。四尊，兩個兵，我。點點頭。

「帶著軍隊來的人。」他說，「好。那就軍隊對軍隊。」

這話我愛聽，公平。

我深吸一口氣，開口，聲音有點抖，但是清楚：「大黑小黑，前面交給你們喔，只擋不追，擋就好。大白去左邊，主教交給你，把杖架開就行。小白右邊，跟著騎士跑，別讓他們繞過來。小草小蕨跟我，補漏子，倒的都拖走！」

七個動了。石頭撞葉甲，響得跟打雷似的。霧散了又聚。主教木杖一揮，風壓過來，大白硬接，推出去三步，又站回來。倒地的哨兵旁邊，另一個主教杖尖冒綠光，往傷口一按，血止住了，哨兵又站起來。我看在眼裡，記在心裡：拿杖的會治傷。這筆先記下，後面算。

小白追騎士，步子重，每步都踩路中間，騎士繞不過去。小草小蕨最活，哪漏補哪，倒的不管哪邊，全拖後面去。

中間空了。剩我，跟王。

他站起來，老高，拿起一支舊矛，矛尖都鈍了。對看一秒，同時動。矛撞矛，喀。虎口裂了，血流下來。但這次我不怕，後面聽得見：咚、咚，四尊還在。我的軍隊還在。

最後一下，我滑進他懷裡，矛尾頂住他喉嚨。他停了。我也停了。

他看著我，笑了一下。

「……好棋。」

血從他嘴角流下來，深色的，跟樹液似的。眼睛閉上，胸口不動了。

王后衝過來，跪下，手指放他鼻子底下。好久。她把他的手合起來，放胸口，搖頭。死了。

全場死了一樣靜。然後，亂了。

兵看騎士，騎士看主教，主教看王后，沒命令下來。頭一回，命令斷了。每顆棋釘在格子上，不知道往哪走。一個兵低頭看自己的矛，跟不認識似的，鬆手，掉進爛葉子裡。

一個騎士按著頭蹲下，嘴裡念個名字，念兩遍，自己停住，想不起來是誰。有個年輕的兵哭了，特別小聲，哭完自己嚇一跳，不知道眼淚哪來的。

跟剛醒的我一樣。空白裡浮著碎片，連不起來。

一個重裝舉刀，憑身體記憶，舉一半，停住，看自己的手，看半天，把刀插回去，退一步。沒人攔他，沒人說話，他自己放下的。

小草按著頭，小蕨往王后那邊邁一步，胸口環閃一下，又暗，停住，回頭看我。我點點頭。牠走回來，站大白旁邊，站筆直。環還在，命令還在。走回來，是命令裡沒寫的第一件事。

咒鬆了。我聞得出來，空氣裡少了點什麼。跟繃久的弦斷了似的。

王后站起來，走到我面前。

「走吧。」她輕聲說，「路在後面。」

我愣住。

「你們……不報仇？」

「報什麼。」她說，「王死了，棋下完了，命令沒了。路在後面，你走你的，我們不擋了。」

她走近一步，按著額頭：「我丟了一個……很小的。留在下面的。是男是女，多大，叫什麼，全想不起來。只記得很輕，抱起來很輕，還有笑，很遠的笑。」她放下手，「你往下走，往環來的地方走。幫我找。找到了，帶話回來。找不到，把你看到的帶回來。」

她走過我身邊，停一下，看我腰間粉筆。

「你手上的粉筆，跟我們身上的環，很像。拿粉筆的人，跟做環的人，很像。你不像，你只是拿著。」

一個年輕妖精自己走出來，背大包，包裡全是葉膏紗布，腰掛根小木杖，眼睛亮亮的，又怕又想跟，站小蕨旁邊，對我點頭，特別用力。

王后看著她，點頭，沒攔。「阿露。主教見習。杖使得不好，包紮比誰都好。」她看我，「下面的火，比這裡兇，帶著，能活。」

「還有這些。」她把幾個包推過來：葉甲、葉靴、葉膏，一大堆，「路上用。別死。」

我抱著包，愣愣點頭。想說謝謝，喉嚨發緊，只擠出一句：「……對不起。還有，謝謝。」

王后沒回答，帶著所有妖精，走進霧裡。霧合上，人全沒了。剩風聲，水聲，葉子聲。

我坐原地，很久。山洞那層，是環綁魔像。

這兒呢，王死了，命令斷了。大家醒過來，跟剛醒的我一樣，空白裡浮著碎片，連不起來。環還脖子上掛著，路還腳底下踩著。往哪走，頭一回沒人說。

這種感覺，我懂。胸口發疼的那種懂。

王座旁邊，一卷舊卷軸，一件葉斗篷。打開卷軸，字浮起來，燙進腦子：噬紋畫法。螺旋，往裡轉，像漩渦。畫地上，站上面的被吸乾力氣。

第二個紋印。手空中描兩下。記住了。

然後記憶來了。木頭桌，方方正正盤，黑白兩邊，棋子是刻出來的馬跟城堡。

時鐘旁邊走，滴答滴答。一個聲音說：兵只能往前，但是兵到底，就能變成任何東西。不要小看兵。

西洋棋。我也下過。教的人手大，指節粗，放我手背上，帶我走第一步。跟圍棋那雙長斑點的手不是一雙。是另一雙，另一個人。不是一個人教的，是好多人，一人教一點。是誰？想不起來。一想就頭疼，跟撞牆似的。

「喂。」操作員聲音，難得先問人，「還活著？心跳亂成這樣，我以為你死了。」

「……活著。靠大家。」

「看到了。四顆石頭，兩個兵，一個沒碎，你行啊。」他翻紙，「數據上，牠們的睿智很高。高得不正常。像沒洗乾淨。」

「洗？」

「沒事。」他岔開，「卷軸拿了？噬紋學了？學了就走。下一層，火。很燙。把斗篷穿上。」

滋——。斷了。斷之前，他補一句，特別小聲：「……這一戰，還算像樣。」

我把斗篷穿上，有點大，拖地。卷軸收好，葉膏分裝。阿露過來幫我綁傷口，手法特熟，一看就練過的。小草小蕨分裝備，大黑用沒裂的那隻手碰了下我的頭。小白學我，盤腿坐下，學我喘氣。大家都笑了——好吧，魔像不會笑，但是牠們眼睛一塊眨了下。我當牠們笑了。

我在心裡數。這層，我一個沒殺。倒的全昏的。隊伍從四個變七個，又變八個。

梯子在王座後面，往下，黑黑的，熱氣冒上來，燙臉。大黑先下，小黑跟著，大白小白，小草小蕨，阿露走中間，我斷後。被大家夾著走，又擠又暖又安全。

——第二局，終了。贏的是八個。
