# 第二章：地下森林

梯子很長。

我先往下爬，四尊魔像一個接一個跟下來。梯井很窄，牠們的肩膀會卡到石壁，掉下灰來，掉得我滿頭都是。大黑第一個下來，小黑第二個，大白小白最後。咚、咚、咚、咚。四聲。聲音在井裡迴盪，像鼓。

到底的時候，風是涼的。

我愣住了。

上面是煙跟血，這裡是水跟葉子。頭頂很高很高的地方，裂縫漏下乳白色的光柱，一道一道，插進霧裡。洞頂鋪滿發光的苔，綠的，藍的，還有一種很淡的紫，一明一滅，像在呼吸。粗大的根從頂上垂下來，像柱子。蕨類比我還高，葉子寬得可以當被子。地上全是落葉，踩下去軟軟的，有水滲出來。

森林。地底有一座森林。

「小聲。」我回頭比了一個手勢，「跟著我，踩我的腳印。」

四尊魔像點頭。我的隊伍，我的四顆棋。

走沒多久，我停下來了。前面霧裡，有聲音。嗒。矛尾敲在石頭上，很脆。一下，又一下。是巡邏。很有規律。

我蹲下來，撥開蕨葉看。

一個妖精。很高，很瘦，皮膚像白樺的皮，又滑又蒼白。耳朵尖尖的，眼睛很大，是銀綠色的，在暗處會反光。身上穿硬硬的葉甲，手裡一支葉矛，拿得很穩。牠走幾步，停下來，聽一聽，再走幾步。是練過的。跟哥布林完全不一樣。這是軍隊。

我縮回來，心跳得很快。一個打一個，我有把握。一個打一支軍隊，我會死。這裡霧這麼大，霧裡有多少支矛，我數不出來。

那就不要硬打。用腦。用大家。

我把四尊叫過來，聲音壓到最低。

「大黑小黑，你們站前面，擋。記住，只擋，不追。牠們刺過來，你們用手臂接，接完推開就好。」我指指兩邊，「大白小白，你們站側面，誰繞過來，你們就往誰前面站一步。不要打，只要擋路。」

四顆頭一起點。灰掉下來。

「我去前面看。你們等我的聲音。我拍兩下手，你們就往前三步。我拍一下，你們就停。」

安排完，我一個人摸過去。貼著根走，踩著落葉走。巡邏隊過去一隊，我數。快的隊，沒多久就回來。慢的隊，隔很久才來。我在心裡畫格子。這裡直走幾步，那裡轉彎幾步，幾步一個彎。跟上面那層一樣，只是這次格子是活的，會走路。

看到落單的了。一隻妖精兵，離隊伍有點遠，在水池邊喝水，矛靠在石頭上。

就是現在。我學鳥叫，兩聲。很難聽，但是夠大。

妖精兵抬頭。大黑小黑從霧裡走出來，一步，兩步，三步，站定。像兩扇門關起來。妖精兵抓起矛就刺。大黑不閃，用手臂接。矛尖在石頭上擦出火星，斷了半截。大白從側面跨一步，擋住牠退回去的路。

妖精兵左右看，慌了。牠把斷矛一丟，轉身就跑，跑的時候還吹了一聲哨。尖尖的，很短。

「退！」我拍一下手。

四尊立刻停步，不追。哨聲把整隊引過來，三隻妖精兵排成一排，矛放平。可是我們已經退回霧裡了，只剩斷掉的矛尖留在地上。牠們搜了一圈，沒找到人，吹了兩聲短哨，整隊退回霧裡，腳步聲遠了，很整齊。連撤退都有規矩。

我躲在根後面，笑了。有效。牠們快，但是牠們照規矩走。規矩摸清楚了，就能騙。

下一個，我想試試粉筆。

等巡邏隊散開，我挑了一隻走最後的兵。粉筆抽出來，沿著牠腳邊的格子描。轉彎，再轉彎，手很穩，心很定。圈合起來的時候，光升起來，跟圍魔像時一模一樣。

妖精兵低頭看了一眼光圈。光閃了兩下，像被風吹的燭火，然後，暗了。粉筆短了一截，灰掉下來。牠抬起腳，從熄掉的圈裡走出來，看了我一眼。銀綠色的眼睛裡沒有怒，只有累。很深很深的累。牠搖搖頭，轉身走了，連步子都沒亂。

我蹲在熄掉的光圈旁邊，想了很久。圍魔像的時候，圈一合就亮了，又穩又暖。這次的圈，亮不起來。是我還不夠強。小的都圍不住，這一層的傢伙，等級比我高，意志比我硬。環接不住牠們。

那就先不圍。先打，先算，先升級。等我變強了，再回來試。

我們這樣打了一整路。敲石頭引一小隊出來，兩尊擋正面，兩尊封側面，我從後面繞進去，用矛尾敲昏最後一個。絕不戀戰，絕不追。受傷的魔像退下來，沒傷的頂上去。我數著，記著，誰的巡邏幾步一回，誰跟誰總是一起走。霧是我們的朋友，根也是。白堊畫的舊線是最好的路，沿著走，不會迷路。

葉膏就是這樣拿到的。敲昏第三個兵的時候，從牠腰上摸下來一包綠綠的膏。抹在傷口上，涼涼的，血很快止住。大黑手臂上的裂口，我也給牠糊了一層。牠低頭看著綠膏，眼睛眨了一下。不知道石頭敷藥有沒有效，但是牠好像很高興。

打到後來，身體變了。說不上來，就是粉筆更燙了，手更穩了，跑起來氣更長了。像是繃緊的弦，又上了一格。升級了。我不知道該怎麼叫它，就叫它升級。

滋滋聲插進來，操作員難得正經：「數據動了。等級二了。繼續。」

等級。原來這東西有等級。上面那層沒有這種感覺，大家都一樣。這一層，身分越高越強，連我也要一級一級往上爬。好，很公平，我喜歡公平。

走到林地深處的時候，霧薄了，光亮了。前面一片開闊地，地上白堊線彎彎曲曲。八個妖精兵，排成一排，站在發光的苔地上。動作一致，連呼吸都一致。像棋盤上的卒子。

卒子。這個詞一出來，我就懂了。上面那層是圍，這層是棋。圍棋的石頭都一樣，擺哪都行。這裡不一樣，這裡每一顆棋都有身分：兵只能往前頂，騎士走側面，主教發號令，重裝像牆一樣擋，王后跟王在最後面。身分不同，打法不同。要贏，就要照著身分打，先吃小的，再找大的。硬衝這條線，我們五個會被串起來。

我繞著開闊地走了一圈，看地形。東邊有水池，很滑。西邊根最多，路最窄。卒子排得齊，可是換防的時候，兩頭總會慢一拍。慢的那一拍，就是洞。

「聽好。」我把四尊叫過來，「等一下我丟石頭，東邊響，牠們會往東看。那時候大黑小黑從西邊進去，只打最邊上那兩個，打完就退。大白小白跟我走，我們去第二邊。不要貪心，一次兩個就好。」

石頭丟出去，啪。東邊的兵轉頭。大黑小黑進去，兩巴掌，兩個兵倒了，立刻退。我帶大白小白從另一邊進，矛尾敲昏一個，推倒一個，也退。剩下四個，陣形亂了，互相喊，互相看。這時候八個變四個，就能打了。四尊排開往前壓，我在後面補，專挑拿矛的手打。一個一個，倒下去。都沒死，全是昏的。我下手的地方全是關節跟脖子，身體自己知道打哪裡會昏不會死。

剩下最後兩個，被逼到水池邊，背靠背，矛舉著，不跑了。小的那個在抖，大的那個把小的往身後擋了一點。

我看著牠們，粉筆在手裡發燙。打穿這一整排，弦又上了一格，升級過的手，穩得很。現在再試，應該成了。我蹲下來，沿著水池邊的濕地描。圈合起來，光升起來，這次又穩又暖，跟圍魔像時一樣。兩個妖精兵低頭看著光，光映在臉上，一閃，一閃，沒有滅。

成了。

光暗下去的時候，兩個兵放下矛，走到我後面站好。小的還在抖，大的拍拍牠。我給牠們取名，大的叫小草，小的叫小蕨。都是路邊的名字，好養。

「跟著石頭走。」我說，「別跑散。」

七個了。我的隊伍，七個。

就是在這個時候，我看到她。

妖精王后。

她站在林地另一頭，比所有的妖精都高。頭髮編起來，戴著一圈葉戒，發出很靜的光。她不停地走，不停地看，走到東邊看看，走到西邊看看。像在找什麼。找了很久，找不到，肩膀垂下來。

然後她看到我們了。看到四尊魔像，看到兩個妖精兵站在我後面，看到我坐在地上喘。她走過來，很慢。我的手握緊矛，大黑舉起手臂。可是她只走到霧邊緣就停了，看著小草小蕨，看了很久，眼神動了一下。像認出了什麼，又不敢認。

「……牠們跟著你。」她說，「自願的？」

我點頭。「圈成的。但是後面，是自願的。」

她沒再問。轉身走了，繼續找。走幾步，回頭看我一眼。那一眼裡沒有殺氣，只有著急。掉了很重要的東西，怎麼找都找不到的那種著急。

我的胸口悶悶的。她在找誰？這裡只有樹，只有霧，只有我們。她要找的人，是不是早就找不到了？

王座在林地最深處。一棵活的大樹，根盤成椅子的形狀。妖精王坐在上面，穿深色葉斗篷。兩邊站著主教，拿彎彎的木杖。外面是重裝哨兵，像兩堵牆。騎士在霧裡走，很快，很輕。

王看著我們。看看四尊魔像，看看小草小蕨，看看我。點點頭。

「帶著軍隊來的人。」他說，「好。那就軍隊對軍隊。」

這是我聽過最公平的話。

我深吸一口氣，下令。聲音抖，但是清楚。

「大黑小黑，正面，擋住哨兵！只擋不追！大白，左邊，主教交給你，把杖架開就好！小白，右邊，跟著騎士跑，別讓牠們繞過來！小草小蕨，跟著我，補空子，倒了的就拖走！」

七個動了。石頭撞上葉甲，聲音大得像打雷。霧被震散，又聚起來。主教的木杖揮出風壓，大白硬接，被推出去三步，又站回來。倒下去的哨兵旁邊，另一個主教杖尖發出綠光，往傷口上一按，血止住了，哨兵又站起來。我看在眼裡，記在心裡：拿杖的會治傷。先記著，這筆帳後面算。小白追著騎士，腳步重，但是每一步都踩在路中間，騎士繞不過去。小草小蕨最靈活，哪裡漏，補哪裡，倒下的不管哪一邊，全拖到後面去。

中間空了。只剩我，跟王。

他站起來，很高，拿起一支很舊的矛，矛尖都鈍了。我們對看了一秒，同時動。矛跟矛撞在一起，喀。虎口裂開，血流下來。但是這次我不怕，因為我聽得到後面：咚、咚，四尊還在，還站著。我的軍隊還在。

最後一下，我滑進他懷裡，用矛尾頂住他的喉嚨。他停了。我也停了。

他看著我，笑了一下。「……好棋。」

然後倒下去，閉上眼睛，不動了。

全場死寂。哨兵舉起刀，主教舉起杖，騎士停下腳——

我閉上眼睛。完了嗎？

矛放下的聲音。一個，接一個。刀插回鞘。杖垂下去。我睜開眼睛，妖精們互相看著，放下武器，退開。王后走過來，蹲在王身邊，把他的手合起來。抬頭看我，很久。

「走吧。」她說，「路在後面。」

我愣住。「你們……不報仇？」

「打完了。輸了就是輸了。」她站起來，「環綁不住我們。我們是自己選的。這一戰，我們選你贏。」

她走過我身邊的時候，停了一下，看著我腰間的粉筆。「你手上的粉筆，跟我們身上的環，很像。」說完拍了兩下手。霧裡走出來一個年輕的妖精，背著大包，包裡全是葉膏跟紗布，腰上掛著一根小小的木杖，眼睛亮亮的，有點怕，又有點想跟。

「阿露。」王后說，「主教見習。杖使得不好，包紮比誰都好。跟她走吧。下面的火，比這裡兇。她需要會治傷的人。」

叫阿露的年輕妖精走過來，站在小蕨旁邊，對我點點頭，很用力。像下了很大的決心。

「還有這些。」王后指指霧裡推出來的幾個包：葉甲、葉靴、葉膏，一大堆，「路上用。別死。」她看著我，很久，又補了一句，「你要守城的那天，學會來去的路了，就回來。森林會回答你。到時候要幾個主教，有幾個。」

我抱著包，愣愣地點頭。想說謝謝，喉嚨有點緊，只說得出一句：「……對不起。還有，謝謝。」

王后沒回答，帶著所有妖精，走進霧裡。霧合起來，人全不見了。只剩風聲，水聲，葉子聲。

我坐在原地，很久。在山洞那層，是環綁住魔像。在這裡，沒有環綁得住誰，王倒了，大家自己放下武器，還有人自己走出來跟我走。被綁住，跟自己選。差很多。差到我胸口發痛。

王座旁邊，一卷舊卷軸，一件葉斗篷。卷軸打開，字浮起來，燙進腦子：噬紋的畫法。螺旋，往內轉，像漩渦。畫在地上，站在上面的人會被吸走力氣。

第二個紋印。手在空中描了兩下。記住了。

然後記憶來了。木頭桌，方方正正的盤，黑白兩邊，棋子是刻出來的馬跟城堡。時鐘在旁邊走，滴答滴答。一個聲音說：兵只能往前，但是兵到底，就能變成任何東西。不要小看兵。

西洋棋。我也下過。教我的人，手比較大，指節比較粗，放在我手背上，帶我走第一步。是跟圍棋同一個人嗎？想不起來。一想就頭痛，像撞到牆。

「喂。」操作員的聲音，難得沒有馬上開嗆，「還活著？心跳亂成這樣，我還以為你掛了。」

「……活著。靠大家。」

「看到了。四顆石頭，兩個兵，一個都沒碎，你行啊。」他翻紙，「數據上，牠們的睿智很高。高到不正常。像沒洗乾淨。」

「洗？」

「沒事。」他岔開，「卷軸拿了？噬紋學了？學了就走。下一層，火。很燙。把斗篷穿上。」

滋——。斷了。斷之前，他補了一句，很小聲：

「……這一戰，指揮得不錯。」

我把斗篷穿上，有點大，拖地。卷軸收好，葉膏分裝。阿露過來幫我綁傷口，手法很熟，一看就是練過的。小草小蕨分裝備，大黑用沒裂的手碰了一下我的頭。小白學我，盤腿坐下來，學我喘氣。大家都笑了——好吧，魔像不會笑，但是牠們的眼睛一起眨了一下。我當牠們笑了。

我在心裡數。這一層，我一個都沒殺。倒的全是昏的。隊伍從四個變成七個，又變成八個。

梯子在王座後面，往下，黑黑的，熱氣冒上來，燙臉。大黑先下，小黑跟著，大白小白，小草小蕨，阿露走中間，我斷後。被大家夾著走，很擠，很暖，很安全。

——第二局，終了。贏的是八個。
