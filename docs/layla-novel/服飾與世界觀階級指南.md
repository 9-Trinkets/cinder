# 蕾拉輕小說・服飾與世界觀階級指南（Costume & Caste Visual Guide）

> 本文件為《蕾拉》（Layla）輕小說視覺、階級服制與角色裝束的**權威規範指南**。
> 四至六層嚴格遵循《使女的故事》（*The Handmaid's Tale*）的極權階級與色彩政治學設計；主角蕾拉則採用**【提案 A：戰地拾荒與拼貼進化型】（Scavenged Pragmatism）**，體現「現代局外人」逐步將被壓迫階級的衣物化為反抗戰袍的演變歷程。

---

## 1. 四至六層極權階級服制體系（The Dystopian Caste System）

深淵的社會結構是一座由現任統治者與聖堂維持的極端極權金字塔。每個階層的穿著不是個人審美的選擇，而是**體制賦予的功能標籤與統治烙印**。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 第 6 層：忘卻聖堂 ── 統治神職（孔雀藍）、聖潔祭品（石膏白/儀式紅）、僕役（枯葉褐）   │
├────────────────────────────────────────────────────────────────────────┤
│ 第 5 層：霜之要塞 ── 平民階級（Econopeople，石板灰/褪色土褐/量產夾棉棉襖）       │
├────────────────────────────────────────────────────────────────────────┤
│ 第 4 層：地熱礦村 ── 殖民地（The Colonies，污濁原麻/煤渣黑/硫磺黃斑/瀝青工號）      │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1 第四層：殖民地（The Colonies）——消耗品與賤民
- **階級定位：** 隨時可被犧牲、等待被抽乾靈魂送往上層的重體力礦工與家屬。被體制視為「正在緩慢損耗的工業零件」。
- **色彩語言：** **污濁未漂白原麻色（Unbleached Burlap）、煤渣黑、硫磺腐蝕黃斑**。
- **服飾材質與剪裁：**
  - **未鎖邊原麻背心與粗麻長褲：** 粗糙扎人，邊緣全是磨損毛邊與破洞。
  - **體制烙印（Stenciled ID）：** 每個人的後頸或後背，都用黑色瀝青油漆噴塗著採掘組別與編號（如小宰德父親的「第七組：西拉傑」）。
  - **防燙與防毒配件：** 口鼻處強制配戴浸過石灰水或草藥汁的粗麻防塵面巾；手腕與小腿纏滿防止蒸汽與高溫礦石燙傷的生牛皮或油布繃帶。
- **代表人物：**
  - **小宰德（Zayd）：** 穿著一件成人改小、袖口磨損捲起的翻領羊毛粗布坎肩，頭上戴著帶有護耳的舊皮帽，口袋裡永遠裝著熱扁餅的碎屑和石子棋。
  - **雅絲敏（Yasmine）：** 繫著滿是麵粉與焦痕的加厚牛皮圍裙，手臂纏著隔熱麻布。

### 1.2 第五層：平民階級（Econopeople）——規格化的勞動齒輪
- **階級定位：** 寒霜要塞的駐防衛兵、機械工匠與城鎮庶民。承擔要塞運轉與生產，生活在被三大家族嚴密監控的寒冬社會中。
- **色彩語言：** **抑鬱沉悶的石板灰（Slate Grey）、褪色土褐、雜色灰暗條紋（Dull Stripes）**。
- **服飾材質與剪裁：**
  - **規格化夾棉防寒短大衣（Econo-coat / Gambeson）：** 統一配發的量產防寒外衣，粗生鐵沖壓金屬鈕扣，內襯加厚羊毛絮。
  - **嚴格禁慾與防寒規訓：** 體制禁止露出喉部與鎖骨，無論男女老少一律將深灰羊毛圍巾嚴密包裹至下巴。
  - **城鎮識別條：** 衣服左肩或左袖口縫有一道兩指寬的暗色布條（暗藍、土黃或鈍紅），用以辨識居住城鎮，未經准許跨區走動將被視為違規。
- **代表人物：**
  - **陳鈺昕與五鎮工匠：** 灰呢棉襖外繫著皮革工具吊帶，雙手生滿凍瘡，衣襬夾雜著防凍油脂的氣味。

### 1.3 第六層：忘卻聖堂（The Sanctuary）——統治者與純潔祭品
- **階級定位：** 高高在上的宗教特權階層，以及被規訓為「無名、無貌」的活體祭品。
- **色彩與外觀分層：**
  - **統治神職／主祭司（Wives / Clergy）：**
    - **色彩：** **深孔雀藍（Teal）、高貴暗湖綠與冷白**。
    - **剪裁：** 裁切極其合身、線條高聳硬挺的厚重精紡羊毛長袍。雙肩與立領高聳，邊緣以刺眼的純金與純銀絲線刺繡出繁複的幾何縛紋與生紋，莊嚴、冷酷且極具壓迫感。
  - **純潔祭品與受訓僕役（Handmaids / Offerings）：**
    - **色彩：** **無瑕刺目的石膏白（Chalk White）**（日常與受訓）或**儀式血紅（Ritual Crimson）**（行將獻祭）。
    - **剪裁：** 從頸部緊扣、一路垂至腳踝的無褶長袍。**嚴格禁止口袋與腰帶**（防止藏匿利器與私念），行動時必須雙手交疊置於腹前。
    - **白瓷半面具（Porcelain Masks）：** 所有人必須配戴無表情純白燒瓷面具，僅開有對稱的窄小眼孔，沒有鼻子與嘴部的立體雕刻，徹底剝奪身為個人的面貌與情緒。
  - **調劑僕役（Apothecary Servants，如奧爾娃）：**
    - 純白長袍外繫著染有乾燥草藥汁液的石榴紅或深棕圍裙，衣袖被細皮帶死死束在小臂上以便勞動。

## 2. 蕾拉（Layla）的現代局外人底層（Base Layer）

身為由高階模擬架構直接投放的人造測試心智，蕾拉自第 0 層甦醒時的穿著，本質上是**現代高規格無標識訓練生機能服（Minimalist Technical Activewear）**。在充滿古典、宗教與蒸氣鐵鏽的世界中，她顯得格格不入且極具科技俐落感：

- **上身：**
  - **消光炭灰色無縫高領壓縮運動長袖（Matte Charcoal Compression Top）**。
  - 具備現代排汗、透氣與貼合肌肉的支撐力，領口有一道隱形的磁吸防風密封邊。
- **下身：**
  - **耐磨立體剪裁工裝彈力慢跑褲（Technical Cargo / Stretch Joggers）**。
  - 膝部與內側大腿有立體幾何拼接，大腿兩側各有一道扁平防水拉鍊袋。
- **足部：**
  - **超輕量黑色越野跑鞋（Trail Runner / Low-profile Boots）**。
  - 無聲深齒橡膠大底，踩在石板幾何網格上不會發出多餘雜音，反饋清晰。
- **面貌與氣質：**
  - 阿拉伯裔少女（微褐膚色、墨黑俐落長髮紮成高馬尾、雙眸深邃如墨）。
  - 全身無鈕扣、無蕾絲、無多餘飄帶，呈現出極致實用、理性的學者／特工美學。

## 3. 提案 A：戰地拾荒與拼貼進化歷程（Scavenged Pragmatism）

> 蕾拉的戰袍是一部「反抗史」。每向下一層，她都在摧毀一個極權階級，並從該階級的殘骸中撕下實用部件穿戴上身。當她抵達終局時，她身上匯聚了整個深淵被壓迫者的血淚與痕跡。

```
第 0～3 層：現代炭黑機能服 ──➔ 墨綠妖精葉斗篷 ──➔ 薩滿骨戒
                                  │
第 4 層（殖民地）：加入【宰德父親厚牛皮圍裙・斜切防燙裙片】＋【琥珀礦燈】＋【粗麻防塵面巾】
                                  │
第 5 層（平民階級）：疊穿【艾絲翠德借予・割除雙袖石板灰平民夾棉長大衣】＋【生鐵防滑冰爪】
                                  │
第 6 層（聖堂）：短暫套上【奪取的純白祭品長罩袍】（潛行），開戰時撕裂長袍露出內部拼貼
                                  │
第 7 層與地表出征：解下多餘防寒負重，回歸【多層拼貼戰鬥姿態】── 率領精銳走向地表真實世界！
```

### 3.1 第 0～3 層：地下棋盤與迷霧林地
- **服飾狀態：** 現代炭黑機能底層。
- **首度添裝（第 1 層）：**
  - 擊破哥布林薩滿後，奪得並佩戴那枚能拘束白石魔像的**薩滿骨戒**於右手無名指。
  - 腰間繫上第一層繳獲的粗皮革多孔外腰帶，掛上石鑿短劍。
- **首度披掛（第 2 層）：**
  - 破解妖精棋局、妖精王棄著投降後，妖精士兵為她獻上一襲由深林硬化古葉編織而成的**深墨綠色硬葉斗篷**。蕾拉將其收窄，以皮帶固定在單肩作為防風與防反光的迷彩披肩。

### 3.2 第 4 層：殖民地（硫磺與地熱蒸汽）
- **氣候危機：** 管道洩漏出高達數百度的滾燙白汽，地面熱水翻滾，空氣中滿是具有微腐蝕性的硫磺粉塵。現代化纖壓縮服在遭遇高溫水花與金屬刮擦時有熔損風險。
- **情感借裝與改造：**
  - 麵包師雅絲敏看見蕾拉身上的衣服單薄容易被燙傷，從後屋翻出了**小宰德父親（西拉傑）生前留在採礦區的厚重耐熱生牛皮圍裙**。
  - 蕾拉接過這件印有模糊「第七組」瀝青黑印的圍裙，取出短劍將上半身切除，改製成一襲**右側高開衩、護住左側與大腿外側的單側戰術皮裙（Asymmetric Tool Apron）**。
  - 蕾拉將小宰德贈予的**黃銅琥珀礦燈**以重生鐵卡扣牢牢掛在皮帶右前方。
  - 面部拉起一條殖民地工匠通用的浸水防塵粗麻巾，遮擋硫磺煙氣。

### 3.3 第 5 層：平民階級（零下二十度暴風雪）
- **氣候危機：** 穿過傳送台踏入第五層，冰原狂風呼嘯，氣溫驟降至零下二十度。透氣的現代壓縮衣在離開要塞熱源十秒內就會讓人失溫凍僵。
- **借裝與標誌性剪裁：**
  - 攻下要塞軍械庫後，艾絲翠德為蕾拉找來了一件**第五層平民規格的暗石板灰夾棉防寒長大衣（Econo-coat）**。
  - **蕾拉的標誌性改造：** 為了保證手腕與手指在繪製「傳紋」與「噬紋」時擁有毫無阻礙的精確幾何弧度，**蕾拉拔出短劍，當著艾絲翠德的面，將大衣手肘以下的寬大棉袖直接齊齊割除**！
  - 割除袖管後，大衣露出了內層緊貼皮膚的黑色壓縮袖與黑色硬皮護腕；蕾拉在大衣內襟用細皮條縫製了專門存放白堊魔粉筆的快拔彈力槽。
  - 腳下套上要塞工匠陳鈺昕緊急打造的生鐵防滑冰爪。

### 3.4 第 6 層：忘卻聖堂（假面、潛入與撕裂）
- **潛入偽裝：**
  - 蕾拉持符石潛入聖堂露台，此處是極端規訓的宗教高地。蕾拉身上滿是煤灰、切袖的平民大衣與現代拉鍊會在一秒內暴露。
  - 蕾拉在修道院僕役洗衣房**順走了一件純白色的純麻祭品長罩袍（White Shroud）**，將自己從頭到腳罩住以遮掩內部的戰鬥裝束。
  - 奧爾娃接頭時，塞給她一枚備用的白瓷假面，但蕾拉**拒絕將抹殺自我的面具戴在臉上**，僅將其倒扣掛在腰側以備盤查。
- **決戰時的階級撕裂（第 11 章）：**
  - 面對主祭司瓦勒利烏斯與骸骨巨龍降臨，長罩袍嚴重限制了滑步與翻滾。
  - 蕾拉反手一劍，**當場將身上的純白長罩袍從正中央徹底撕裂甩飛**！
  - 狂風中，她露出了裡面的全套行頭——**炭黑現代機能衣＋殖民地防燙皮裙＋割袖灰平民長風衣**。這一幕在視覺上極具震撼力：被體制視為最卑賤的下層勞動者服飾，在此刻化為了斬殺神職統治者的弒神之服。

### 3.5 第 7 層與地表出征（邁向真實世界）
- **終局卸裝：**
  - 在第十二章進入純白前廳與老操作員對弈前，蕾拉解下了笨重的防寒外披，重新將身形收束為最俐落、最敏捷的狀態。
  - 她的魔粉筆化為金粉消散，但她的身上永遠留下了深淵的印記：被汗水與硝煙浸透的炭黑機能衣、腰間閃爍著永恆暖光的琥珀礦燈、手腕處由殖民地粗麻包裹的防護帶。
- **踏出地表時的視覺衝擊：**
  - 當晨風吹拂過她的臉龐，身後的艾絲翠德身披重鎧、妖精先鋒身著硬葉甲，而蕾拉站在最前方，身著俐落的現代黑衣與流亡戰袍。
  - 她們不是歸鄉的難民，而是一支**由人造心智與異界反叛者組成的精銳遠征隊**，準備叩響現實世界造物主的大門。

## 5. 寫作中的感官描寫指引（Sensory Rules）

1. **強調衣物的物理重量與聲音：**
   - 描寫蕾拉時：強調「無聲的薄底鞋踩在石格線上」、「尼龍彈力布料摩擦的細微刷刷聲」。
   - 描寫極權底層時：強調「粗麻刺磨皮膚的搔癢感」、「殖民地圍裙上的酸腐硫磺氣味」、「石板灰棉大衣浸透雪水後的沉重冷硬」。
2. **動作與衣服的互動（Interactive Costuming）：**
   - 畫紋時：蕾拉會本能地抬手確認小臂的自由度（呼應她割掉大衣袖子的舉動）。
   - 緊張或思考時：她的手指會習慣性地摸過腰間琥珀礦燈冰涼的水晶護罩，感受內部傳來的微溫。
3. **服飾即對抗：**
   - 任何涉及衣服的場景，都不可寫成純粹的「換裝展示」，必須是**生存需要逼迫下的戰術改裝**。蕾拉的每一次修剪、穿戴與撕裂，都是她奪回身體控制權與主動權的行為宣言。
