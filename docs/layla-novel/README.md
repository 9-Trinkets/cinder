## 寫作規則

1. **一人稱蕾拉加雙聲道**：內心獨白（數格子、量角度）加操作員無線電。
2. **規則即技能**：每個紋印都是「手先想起來」。任務只寫做什麼，不寫怎麼做。
3. **台式繁中輕小說**：短句、密分段、多對話、一行吐槽。國中生也讀得懂。
4. **敵人寫物不寫惡**：寫泥灰、濕毛、樺皮、硫磺，不寫邪惡。
5. **每章骨架**：感官冷開場 → 規則發現 → 一戰或一解 → 記憶閃光 → 操作員歪樓 → 收在燈或線或棋。
6. **人名地名全中文化**：正文不夾英文、不附原文，一律用翻譯對照表定名。
