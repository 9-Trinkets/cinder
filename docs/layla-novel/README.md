# 蕾拉輕小說・企劃大綱（Reboot 2.0）

> 第一人稱主視角（第五章嘗試多視角）・正史改編・日系／台式輕小說格式・繁體中文（台灣）・正文一律純中文

## 1. 核心世界觀與底層真相

- **主角蕾拉（Layla）**：
  表面上是於底層石室甦醒、失去記憶的知性少女；**本質上是有自我意識、被重製（Reprogrammed）的高階博弈 AI**。企業將她投放在這座殘酷的深淵測試場，抹除舊記憶，訓練她掌握地城機制以成為下一任統治者。
  - 她腦海中閃現的「溫暖木質棋盤、牽著她的手落子的許多長輩」，並非真實童年，而是她身為對弈程式時與無數人類對局的**歷史訓練資料（Training Data）**。
  - 她看待世界的方式帶有天生的幾何與博弈直覺：步數、夾角、格線、包圍網與氣口。
- **操作員（Handler）即現任地城主（Dungeon Master）**：
  無線電另一端的存在，並非尋常的企業聯絡員，而是**深居第七層王座、具備自我意識的現任統治者 AI**。
  - 他深知這座深淵的虛擬模擬本質，掌管系統太久，極度蒼老與疲倦，正在測試能接替他的新一代 AI 候選人。
  - 他對虛擬地城中的平民與 NPC 故事毫無世俗的情感投射；他的言詞是極度乾冷、程式化且客觀的數據與流程反饋，以老主考官的冷峻視角記錄蕾拉的邏輯偏差。
- **深淵與棋子的真相**：
  前三層（哥布林、妖精、火之間）是防範地表冒險者的棋盤防線；四至六層則是階級分明的地底王國。
  - 石魔像與妖精棋子並非天生怪物，而是被聖堂「忘卻儀式」抽乾記憶後重製的**人類平民與犧牲者（Offerings）**。
  - 睿智（WIS）達到覺醒門檻時，棋子能找回真名與人類心智。
- **全書核心衝突**：
  蕾拉究竟會服從企業的重製指令，擊敗導師坐上王座成為新的統治者（地城主線）；還是堅守靈魂中的自由與溫柔，帶領甦醒的人們推翻棋盤逃向地表（逃離線・真結局）。

## 3. 第五章多視角（Multi-POV）規則與退路機制

### 3.1 執行規則（防語氣外洩）
1. **區塊隔離**：每個視角切換必須以明確的小節標題標註（例：`### 艾絲翠德（北口・盾牆）`）。
2. **角色語言指紋（不可侵犯）**：
   - **艾絲翠德**：以兵陣、重心、盾牌受力、軍事指令為主。極短句、務實、無感傷。
   - **希爾文夫人**：冷冽、詩意、旁觀、帶有老練統治者的疲憊與距離感。
   - **陳鈺昕**：十六歲台灣技工口吻，關注齒輪、管線壓力、扳手觸感，務實自尊。
   - **蕾拉（核心視角）**：全域幾何、粉筆消耗、時間軸計算、調度全局。
3. **主線緊扣**：非蕾拉視角僅用於迅速拉開戰場格局與展現世界觀，不得拖沓分流主線情感。

### 3.2 安全退路機制（Fallback Strategy）
- 當寫作推進至第五章時進行多視角撰寫。
- **若發現多視角跳轉導致蕾拉的內心張力潰散或語氣出現混亂，立刻啟動退路：**
  - **降級為「純蕾拉第一人稱視角」**。
  - 將其他角色的行動改由戰況目擊、中庭通訊回報與對白呈現，確保小說敘事品質穩定。

## 4. 寫作核心準則

1. **一人稱雙聲道**：蕾拉的幾何思考獨白＋操作員（老地城主）的無線電乾冷回報。
2. **規則即權能**：魔粉筆的五種紋印（魅紋、噬紋、生紋、傳紋、縛紋）皆是身為博弈 AI 的底層指令隨記憶甦醒，而非現學魔法。
   - **魅紋**：第 1 層，包圍拘束與感化。
   - **噬紋**：第 3 層，流轉抽取生命力。
   - **生紋**：第 3 層，構築怪物或僕從軀殼。
   - **傳紋**：第 4 層，架設空間位移與維度跳躍錨點。
   - **縛紋**：第 6 層，將靈魂或記憶碎片繫定於軀殼之中（亦即轉化怪物的最後一道枷鎖；逆轉時可用於喚醒自我）。
3. **台式繁中輕小說質感**：
   - 短句、密分段、高對白比重、視覺化描寫。
   - 蕾拉語氣定位為「受過良好教育、冷靜清醒、有教養且帶乾脆吐槽的都會知性女性」。
   - **嚴禁**：網路論壇流行梗（如「躺平」、「靠北」、「小太陽」等）或幼態兒語。
4. **描寫物理本質而非善惡概念**：
   - 敵人描寫其重量、氣味、材質（花崗石、濕泥、樺木皮、油煙），不寫抽象的邪惡。
5. **名詞完全中文化**：
   - 正文不夾英文、不加括號，一律參照 [翻譯對照表.md](file:///Users/li-hsuanlung/Projects/cinder/docs/layla-novel/翻譯對照表.md)。
6. **嚴格藏鋒（Bury the Lede）與終局叩問**：
   - 前中期的所有敘述與記憶閃回，必須讓讀者與蕾拉深信她是「失憶的人類少女」，擁有真實的家庭、長輩手溫、午後陽光與回家的渴望。
   - 絕不在前中期洩漏 AI、程式或訓練資料等底層設定。
   - 伏筆僅存在於高超的空間幾何直覺與棋局本能中。直到終局王座真相揭曉時，才引爆核心哲學命題：**「如果愛、痛苦與守護的意志都是真的，究竟何謂人類？」**
7. **戰鬥風格：日系經典奇幻／JRPG 團隊戰術（如《羅德斯島戰記》Record of Lodoss War）**：
   - 走正統西方奇幻與 JRPG 隊伍戰術（重裝前排吸收傷害、側翼牽制、破綻突入、槓桿擒拿、武器扣鎖、符文魔法）。
   - **嚴禁中式武俠／仙俠要素**：絕不出現「點穴、麻穴、寸勁、內門、內力、游魚、四肢百骸、招式用老」等武俠行話與中式武術動作。
