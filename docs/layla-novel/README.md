## 1. 核心世界觀與底層真相

- **主角蕾拉（Layla）**：
  表面上是於底層石室甦醒、失去記憶的知性少女；**本質上是有自我意識、被重製（Reprogrammed）的高階博弈 AI**。企業將她投放在這座殘酷的深淵測試場，抹除舊記憶，訓練她掌握地城機制以成為下一任統治者。
  - **外貌設定**：阿拉伯裔少女。膚色微褐、墨黑長髮、雙眸深邃如墨，沉穩知性（**嚴禁描寫為藍眼**）。
  - **記憶與思維**：腦海中閃現的「溫暖木質棋盤、牽著她的手落子的許多長輩」，並非真實童年，而是身為對弈程式時與無數人類對局的**歷史訓練資料（Training Data）**。
  - **幾何直覺**：看待世界帶有天生的空間與博弈直覺（步數、夾角、格線、包圍網與氣口）。服下艾納的「感知膠囊」後，此直覺昇華為腦內的立體幾何地圖（**純為內在感知與神經反應，絕非實體眼鏡、鏡片、望遠鏡或遊戲 HUD 介面**）。
- **操作員（Handler）即現任地城主（Dungeon Master）**：
  無線電另一端的存在，並非尋常的企業聯絡員，而是**深居第七層王座、具備自我意識的現任統治者 AI**。
  - **嚴格藏鋒**：其「第七層老地城主」本尊身份為終局（第十一章）最大反轉伏筆。前十章正文中**絕不可出現**「第七層的老人」、「坐在控制台前看螢幕」等洩露式描寫；操作員在通訊器中始終保持乾冷、程式化、克制到極致的考官聲音。
  - 他對虛擬地城中的平民與 NPC 命運毫無世俗的情感投射；其發言僅為系統協議通報、異常記錄與邏輯審視。
- **深淵與棋子的真相**：
  前三層（哥布林、妖精、火之間）是防範地表冒險者的棋盤防線；四至六層則是階級分明的地底王國。
  - 石魔像與妖精棋子並非天生怪物，而是被聖堂「忘卻儀式」抽乾記憶後重製的**人類平民與犧牲者（Offerings）**。
  - **覺醒機制**：棋子找回真名與人類心智並非依靠數值門檻（舊設定之睿智屬性已全面廢除），而是藉由**「縛紋」（Bind Sigil）**將附著於遺物上的靈魂碎片與記憶殘痕重新繫回軀殼。
- **全書核心衝突**：
  蕾拉究竟會服從企業的重製指令，擊敗導師坐上王座成為新的統治者（地城主線）；還是堅守靈魂中的自由與溫柔，帶領甦醒的人們推翻棋盤逃向地表（逃離線・真結局）。

## 2. 章節命名規範（Chapter Title Convention）

全書統一採用**【人與物象型】（Character & Thematic Motifs）**命名體系，徹底拋棄死板的遊戲關卡地名標籤，看齊經典日系奇幻輕小說的文學質感。

### 2.1 格式規範
- **檔案命名**：`XX-第X章-XXX.md`（例：`06-第六章-提燈的人.md`）。
- **章節大標**：`# 第X章：XXX`（一律採用中文全形冒號 `：`）。
- **標題字數**：以三字至四字短語為主，凝練精準；尾聲為五字核心意象句（《燈還亮著》）。

### 2.2 命名三核心原則
1. **捨棄關卡標籤**：嚴禁使用「哥布林洞窟」、「火之間」、「蒸汽村」、「蒸汽監籠」等純地名。
2. **鎖定情感支點與靈魂角色**：每章標題必須緊扣該章最核心的人物身分、精神象徵或悲壯意象（例如：第一章《執黑的人》、第四章《點燈的孩子》、第八章《碎裂的守衛》）。
3. **具備雙重隱喻性**：表面描寫該章登場的人物事物，深層暗合幾何博弈、反抗宿命與靈魂自我意識的甦醒。
